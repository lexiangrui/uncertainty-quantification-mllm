# GASP-UQ 具体工程实现

## 1. 当前方法

```python
METHOD_VERSION = "gasp-predictive-visual-noisy-or-v7"
PERTURBATION_SEEDS = (11, 23, 37, 53, 71)
SENSITIVE_TOKEN_RATIO = 0.10
REPLACEMENT_NOISE_SCALE = 1.0
NORM_ISOTROPIC_SIGMA = 0.01
SEMANTIC_VOLUME_JITTER = 1e-6
```

文本扰动已完全移出主流程。每个样本执行一次基础生成、一次梯度前向和五次视觉扰动前向。

## 2. 两种视觉扰动

命令行参数：

```bash
--perturbation-mode replace
--perturbation-mode norm_isotropic --norm-isotropic-sigma 0.01
```

- `replace`：原有的尺度匹配高斯向量完全替换；
- `norm_isotropic`：直接执行“原 token 加 $\sigma$ 倍标准高斯噪声 → 投影回原 token 范数”。不对噪声方向预先做范数匹配。

每条记录写入：

```json
"perturbation": {
  "mode": "norm_isotropic",
  "norm_isotropic_sigma": 0.01
}
```

`--resume` 同时检查方法版本、模式和 $\sigma$。

## 3. 分数实现

`perturb.py::visual_dependency_scores`：

```python
visual_dependency = 0.5 * (nll_dependency + volume_dependency)
visual_ungrounded_risk = 1.0 - visual_dependency
```

`perturb.py::combined_uncertainty`：

```python
uncertainty = 1.0 - (
    (1.0 - predictive_uncertainty)
    * (1.0 - visual_ungrounded_risk)
)
```

其中：

```python
predictive_uncertainty = 1.0 - math.exp(-nll0)
```

单元测试覆盖两个约束：低预测置信度或视觉无依赖任一出现时，总不确定性都增大；固定预测不确定性时，更大的视觉变化必须降低总不确定性。

## 4. 输出 schema

```json
{
  "method_version": "gasp-predictive-visual-noisy-or-v7",
  "perturbation": {"mode": "norm_isotropic", "norm_isotropic_sigma": 0.01},
  "correct": false,
  "error_label": 1,
  "scores": {
    "nll0": 0.0,
    "predictive_uncertainty": 0.0,
    "visual_nll_dependency": 0.0,
    "visual_volume_dependency": 0.0,
    "visual_dependency": 0.0,
    "visual_ungrounded_risk": 0.0,
    "uncertainty": 0.0
  },
  "visual_perturbed_nlls": [],
  "visual_semantic_volume": {}
}
```

不再输出 `hallucination`、`hallucination_label`、`hallucination_rate` 或任何 `text_*` 字段。

## 5. AUROC 与高置信子集

AUROC 统一以逐问题错误为正类：

```python
error_label = int(not correct)
roc_auc_score(error_labels, uncertainty)
```

summary 包含：

- `accuracy` 和 `sample_error_rate`；
- `predictive_uncertainty`、`visual_ungrounded_risk`、总体 `uncertainty` 的 error AUROC/AUPRC；
- `S_V` 只取 NLL 依赖或只取语义体积依赖时的总体不确定性消融及 AUROC CI；
- 视觉依赖分量以正确回答为正类的诊断 AUROC；
- `predictive_uncertainty` 最低 25%/50% 的高置信子集里，视觉风险与总体不确定性的 AUROC。

## 6. HallusionBench images

完整运行：

```bash
sbatch slurm/gasp/run_hallusionbench_images_full.sbatch
```

范数保持加性扰动：

```bash
sbatch slurm/gasp/run_hallusionbench_norm_isotropic.sbatch

# 覆盖强度或先跑小样本
NORM_ISOTROPIC_SIGMA=0.1 LIMIT=8 \
  sbatch slurm/gasp/run_hallusionbench_norm_isotropic.sbatch
```

`replace` 默认输出为：

```text
results/gasp/hallusionbench_images_replace_v7.jsonl
results/gasp/hallusionbench_images_replace_v7.summary.json
```

版本检查禁止不同版本、扰动模式或强度写入同一结果。
