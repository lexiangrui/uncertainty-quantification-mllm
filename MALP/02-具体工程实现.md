# MALP-UQ 具体工程实现：扰动部分

> **版本提示**：本文的 projector/text-embedding `stage2` 内容是旧版实现记录。
> 当前代码使用融合后 `language_model` 输入扰动，以及 LLaMA 第 15--20 层
> self-attention 输出扰动；请以
> [03-融合与推理扰动实现.md](03-融合与推理扰动实现.md) 为当前权威说明。

## 1. 实现范围

本文档只描述 MALP-UQ 的工程实验实现中与“扰动”直接相关的部分，包括：

- 目标模型的输入准备与固定回答；
- 视觉 embedding 与文本 embedding 的拆分；
- 各向同性高斯扰动；
- 梯度 Top-K 局部扰动；
- 阶段分层扰动的注入位置与 hook 设计；
- 扰动结果的中间文件保存与基础校验。

本文档暂不实现、也不展开以下内容：

- 更复杂的最终论文分数组合；
- AUROC、AUPR、bootstrap 等评估；
- Judge 标注与幻觉标签构造；
- 大规模网格搜索和最终论文表格。

也就是说，当前阶段优先保证“能稳定地拿到模型内部表示，并按方案定义对指定模态、指定 token、指定阶段注入可复现扰动”。基础比较脚本当前计算 PIS 与回答 token KL。

## 2. 实现原则

第一版不做通用多后端框架，优先实现一个可跑通、可检查、可复现实验路径。

固定设置：

- 目标 LVLM：LLaVA-1.5-7B；
- 扰动位置主线：Projector 输出、LLM 输入前的多模态 embedding；
- 扰动类型：范数保持随机扰动与沿向量方向高斯扰动；
- 梯度版本：只选择高梯度 token 子集扰动；
- 阶段版本：只预留 hook 与缓存接口，先实现 Stage 1 和 Stage 2，Stage 3/4 后续再补；
- 运行位置：MiliLab Slurm GPU 节点；
- 模型和数据：读取集群 `/opt/lexiangrui/models/` 与 `/opt/lexiangrui/datasets/`。

工程上坚持三点：

1. **扰动发生在 embedding / hidden state 层，不改原始图片和原始文本字符串。**
2. **生成回答只做一次，后续所有扰动前向都固定该回答并使用 teacher forcing。**
3. **扰动函数只负责产出被扰动的张量或 hook，不负责计算最终不确定性指标。**

## 6. 模型封装

`model.py` 直接使用 Transformers 的 LLaVA 实现：

```python
import torch
import torch.nn.functional as F
from transformers import AutoProcessor, LlavaForConditionalGeneration

from config import LLAVA_MODEL, MAX_NEW_TOKENS


class LlavaMalpRunner:
    def __init__(self, model_path=LLAVA_MODEL):
        self.processor = AutoProcessor.from_pretrained(
            model_path,
            local_files_only=True,
        )
        self.model = LlavaForConditionalGeneration.from_pretrained(
            model_path,
            dtype=torch.float16,
            device_map="cuda:0",
            local_files_only=True,
            attn_implementation="sdpa",
        ).eval()
        for parameter in self.model.parameters():
            parameter.requires_grad_(False)
        self.device = next(self.model.parameters()).device
        self.vision_tower = self.model.model.vision_tower
        self.projector = self.model.model.multi_modal_projector
```

需要提供以下函数：

```python
def prepare_inputs(image, question: str) -> dict[str, torch.Tensor]:
    ...

def greedy_generate(inputs: dict[str, torch.Tensor]) -> dict:
    """返回 answer_text 与 answer_ids。"""

def build_teacher_forcing_inputs(
    inputs: dict[str, torch.Tensor],
    answer_ids: torch.Tensor,
) -> dict[str, torch.Tensor]:
    """拼接 prompt 与固定回答，返回 full_ids、full_attention、prompt_length。"""

def forward_with_embedding_perturbation(
    teacher_inputs: dict[str, torch.Tensor],
    perturb_spec: "PerturbSpec",
) -> dict:
    """在指定模态 / 阶段注入扰动，返回 logits 与必要的调试信息。"""
```

### 6.1 固定回答生成

每条样本先用原始输入 greedy decoding 一次：

```python
@torch.inference_mode()
def greedy_generate(self, inputs):
    prompt_length = inputs["input_ids"].shape[1]
    sequences = self.model.generate(
        **inputs,
        do_sample=False,
        max_new_tokens=MAX_NEW_TOKENS,
        use_cache=True,
    )
    answer_ids = sequences[:, prompt_length:]
    answer_text = self.processor.batch_decode(
        answer_ids,
        skip_special_tokens=True,
    )[0].strip()
    return {
        "answer_text": answer_text,
        "answer_ids": answer_ids.detach(),
    }
```

后续扰动前向全部使用这组 `answer_ids`，不重新生成。这样扰动实验测的是固定回答在不同 latent 输入下的概率变化，而不是采样输出文本的变化。

### 6.2 Teacher-forcing 拼接

```python
def build_teacher_forcing_inputs(self, inputs, answer_ids):
    prompt_ids = inputs["input_ids"]
    prompt_attention = inputs["attention_mask"]
    full_ids = torch.cat([prompt_ids, answer_ids], dim=1)
    full_attention = torch.cat(
        [
            prompt_attention,
            torch.ones_like(answer_ids, device=prompt_attention.device),
        ],
        dim=1,
    )
    return {
        "input_ids": full_ids,
        "attention_mask": full_attention,
        "pixel_values": inputs["pixel_values"],
        "prompt_length": prompt_ids.shape[1],
        "answer_length": answer_ids.shape[1],
    }
```

当前文档不写 NLL 计算，但必须保留 `prompt_length` 和 `answer_length`，因为后续指标模块需要用它们对齐回答 logits。

## 7. 多模态 embedding 拆分

MALP 的核心要求是区分视觉 token 和文本 token。LLaVA 的处理方式是：文本中有 image placeholder，模型内部将视觉 projector 输出替换到对应位置。

第一版采用 hook 方式，不手动重写 LLaVA 的全部 embedding merge 逻辑：

- Stage 1：hook `vision_tower` 输出，即 CLIP / ViT 输出；
- Stage 2：hook `multi_modal_projector` 输出，即视觉 token 映射到 LLM hidden size 后的表示；
- 文本 embedding：hook LLM token embedding 层输出，并根据 `input_ids` 排除 image placeholder 对应区域。

### 7.1 视觉 token 获取

Projector 输出形状约定为：

```python
visual_tokens: torch.Tensor  # [batch, num_visual_tokens, hidden_size]
```

LLaVA-1.5-7B 默认通常为：

```text
num_visual_tokens = 576
hidden_size = 4096
```

实际实现中不要硬编码 hidden size，只在 smoke test 中检查 token 数是否符合预期：

```python
if visual_tokens.ndim != 3:
    raise AssertionError("visual tokens must be [B, Nv, D]")
if visual_tokens.shape[1] != 576:
    raise AssertionError(f"expected 576 visual tokens, got {visual_tokens.shape[1]}")
```

### 7.2 文本 token 获取

文本 embedding 来自：

```python
text_embedding_layer = self.model.get_input_embeddings()
```

hook 输出形状：

```python
text_embeddings: torch.Tensor  # [batch, sequence_length, hidden_size]
```

文本扰动只作用于 prompt 中的真实文本 token，不作用于：

- padding token；
- image placeholder token；
- 后续拼接的 answer token。

因此需要构造文本扰动 mask：

```python
def build_text_prompt_mask(input_ids, attention_mask, prompt_length, image_token_index):
    mask = attention_mask.bool()
    mask[:, prompt_length:] = False
    mask &= input_ids.ne(image_token_index)
    return mask
```

如果当前 Transformers 版本中 image token index 字段名不同，优先从模型配置读取：

```python
image_token_index = getattr(self.model.config, "image_token_index", None)
```

读不到时在初始化阶段直接报错，不做猜测。

## 8. 扰动规格对象

`perturb.py` 中定义一个轻量规格对象，描述一次扰动应该注入到哪里：

```python
from dataclasses import dataclass
from typing import Literal

import torch


@dataclass(frozen=True)
class PerturbSpec:
    modality: Literal["vision", "text"]
    stage: Literal["stage1", "stage2", "stage3", "stage4"]
    mode: Literal["norm_isotropic", "directional", "adversarial"]
    sigma: float
    gamma: float
    seed: int
    token_mask: torch.Tensor | None = None
    adv_gradient: torch.Tensor | None = None
```

字段含义：

| 字段 | 含义 |
|---|---|
| `modality` | 扰动视觉侧还是文本侧 |
| `stage` | 注入阶段 |
| `mode` | 扰动方法：范数保持随机扰动、方向扰动或对抗梯度扰动 |
| `sigma` | 视觉基础扰动强度 |
| `gamma` | 文本侧平衡因子；当前固定为 `1.0` |
| `seed` | 当前 Monte Carlo 采样的随机种子 |
| `token_mask` | 可选 token mask，用于梯度 Top-K 局部扰动 |
| `adv_gradient` | `adversarial` 模式使用的 Stage-2 embedding 梯度 |

文本扰动的实际强度为：

```python
effective_sigma = sigma * gamma
```

视觉扰动的实际强度为：

```python
effective_sigma = sigma
```

## 9. 基础扰动函数

### 9.1 原始各向同性高斯扰动

```python
def sample_isotropic_noise(
    target: torch.Tensor,
    *,
    seed: int,
) -> torch.Tensor:
    generator = torch.Generator(device=target.device).manual_seed(seed)
    return torch.randn(
        target.shape,
        generator=generator,
        device=target.device,
        dtype=target.dtype,
    )
```

扰动：

```python
perturbed = target + effective_sigma * noise
```

当前主实验不直接使用该原始版本作为基础随机扰动；基础随机扰动使用 9.3 节的范数保持版本。

### 9.2 范数保持工具

范数保持指加完扰动后，将新的 token embedding 投影回原 token 的长度：

```python
def preserve_token_norm(perturbed: torch.Tensor, target: torch.Tensor) -> torch.Tensor:
    target_norm = target.float().norm(dim=-1, keepdim=True).clamp_min(1e-12)
    perturbed_norm = perturbed.float().norm(dim=-1, keepdim=True).clamp_min(1e-12)
    return (perturbed.float() * (target_norm / perturbed_norm)).to(dtype=target.dtype)
```

经过这一步后满足：

```python
preserve_token_norm(perturbed, target).norm(dim=-1) == target.norm(dim=-1)
```

也就是控制扰动后的 embedding 长度不变，而不是控制扰动向量本身的长度。

### 9.3 norm-preserving isotropic

```python
def sample_norm_isotropic_noise(target: torch.Tensor, *, seed: int) -> torch.Tensor:
    raw_noise = sample_isotropic_noise(target, seed=seed)
    return normalize_noise_to_token_norm(raw_noise, target)

noise = sample_norm_isotropic_noise(target, seed=seed)
perturbed = target + effective_sigma * noise
perturbed = preserve_token_norm(perturbed, target)
```

这里仍先把随机方向缩放到与原 token 同长度，用 `sigma` 控制临时移动步长；随后再把加扰动后的 token 投影回原范数。代码模式名仍为 `norm_isotropic`，但当前语义是“基础随机扰动 + 范数保持”。

### 9.4 directional noise

```python
def sample_directional_noise(target: torch.Tensor, *, seed: int) -> torch.Tensor:
    # 每个 token 采样一个高斯标量，沿 token 自身方向连续扰动。
    generator = torch.Generator(device=target.device).manual_seed(seed)
    coefficients = torch.randn(target.shape[:-1] + (1,), generator=generator, device=target.device)
    return target * coefficients
```

当前该方法不额外做范数归一化，也不做范数保持。它直接产生沿自身方向的高斯标量扰动。

### 9.5 adversarial gradient noise

对固定生成序列做一次 teacher-forcing 前向，计算总对数概率：

```python
log_probs = F.log_softmax(response_logits.float(), dim=-1)
selected = log_probs.gather(-1, answer_ids.unsqueeze(-1)).squeeze(-1)
objective = selected.sum()
objective.backward()
```

hook 捕获 Stage-2 embedding，并读取它关于 `objective` 的梯度。视觉侧捕获 projector 输出，文本侧捕获 input embedding 输出：

```python
tracked = output.detach().requires_grad_(True)
trace["embedding"] = tracked
return tracked
```

梯度计算入口同时返回该次未扰动 forward 的回答位置 logits。主流程启用
`adversarial` 时直接复用第一次梯度 forward 的 logits 计算原始 NLL 和后续 KL，
避免再执行一次内容完全相同的 `forward_original()`。

扰动方向使用负梯度单位方向，每个 token 采样一个非负高斯标量，并将扰动长度匹配到 `directional`：

```python
step = torch.randn(target.shape[:-1] + (1,), generator=generator, device=target.device).abs()
gradient_direction = gradient / gradient.norm(dim=-1, keepdim=True).clamp_min(1e-12)
noise = -step * target.norm(dim=-1, keepdim=True) * gradient_direction
```

最终仍然走统一外层强度控制：

```python
perturbed = target + effective_sigma * noise
```

因此三种方法都是视觉侧用 `sigma`，文本侧用 `sigma * gamma`。其中 `adversarial` 与 `directional` 使用相同的逐 token 扰动长度分布 `|alpha| * ||target||`，只把方向从 token 自身方向改为负梯度方向。

### 9.6 Token mask

基础版本不传 `token_mask`，即扰动所有目标 token。

梯度版本传入形状为 `[B, N]` 或 `[B, N, 1]` 的 mask：

```python
def apply_token_mask(noise: torch.Tensor, token_mask: torch.Tensor | None) -> torch.Tensor:
    if token_mask is None:
        return noise
    mask = token_mask.to(device=noise.device, dtype=noise.dtype)
    while mask.ndim < noise.ndim:
        mask = mask.unsqueeze(-1)
    return noise * mask
```

被 mask 排除的 token 必须完全保持原值：

```python
perturbed = target + effective_sigma * apply_token_mask(noise, token_mask)
```

单元测试需要验证：

```python
unchanged = token_mask == 0
assert torch.equal(perturbed[unchanged], target[unchanged])
```

对于 float 张量，若索引后形状不方便，可用：

```python
max_diff = ((perturbed - target) * (1 - mask)).abs().max()
assert max_diff.item() == 0
```

## 10. 当前校准设置

当前主流程保留 `norm_isotropic`、`directional` 和 `adversarial`，不需要数据集级标准差或协方差校准。`gamma` 固定为 `1.0`。三种方法的外层强度均由 `sigma/gamma` 统一控制。

## 11. Stage 2：Projector 输出扰动

Stage 2 是第一版主实现，最贴近方案中的：

```text
Visual Encoder → Projector → LLM input embedding
```

### 11.1 视觉扰动 hook

对 `multi_modal_projector` 注册 forward hook：

```python
def make_projector_perturb_hook(spec: PerturbSpec):
    def hook(_module, _inputs, output):
        if spec.modality != "vision" or spec.stage != "stage2":
            return output
        return perturb_tensor(output, spec)
    return hook
```

注册与清理：

```python
handle = self.projector.register_forward_hook(make_projector_perturb_hook(spec))
try:
    outputs = self.model(...)
finally:
    handle.remove()
```

任何 hook 都必须放在 `try/finally` 中移除，避免下一次前向被污染。这是扰动实验最容易偷偷出错的地方，单元测试要覆盖。

### 11.2 文本扰动 hook

对 input embedding 层注册 forward hook：

```python
embedding_layer = self.model.get_input_embeddings()
```

hook 内只扰动真实 prompt 文本 token：

```python
def make_text_embedding_perturb_hook(spec: PerturbSpec, text_prompt_mask: torch.Tensor):
    def hook(_module, _inputs, output):
        if spec.modality != "text" or spec.stage != "stage2":
            return output
        spec_with_mask = replace(spec, token_mask=text_prompt_mask)
        return perturb_tensor(output, spec_with_mask)
    return hook
```

这里的 `output` 包含 prompt token 和 answer token。mask 必须把 answer token 置零，保证固定回答本身的 token embedding 不被扰动。MALP 的文本扰动对象是问题 $Q$，不是回答 $\mathbf y$。

### 11.3 Stage 2 前向入口

```python
def forward_with_stage2_perturbation(self, teacher_inputs, spec):
    handles = []
    try:
        if spec.modality == "vision":
            handles.append(
                self.projector.register_forward_hook(
                    make_projector_perturb_hook(spec)
                )
            )
        elif spec.modality == "text":
            text_prompt_mask = build_text_prompt_mask(...)
            handles.append(
                self.model.get_input_embeddings().register_forward_hook(
                    make_text_embedding_perturb_hook(spec, text_prompt_mask)
                )
            )
        else:
            raise ValueError(spec.modality)

        with torch.inference_mode():
            outputs = self.model(
                input_ids=teacher_inputs["input_ids"],
                attention_mask=teacher_inputs["attention_mask"],
                pixel_values=teacher_inputs["pixel_values"],
                use_cache=False,
                return_dict=True,
            )
        return {
            "logits": outputs.logits.detach(),
            "stage": spec.stage,
            "modality": spec.modality,
            "seed": spec.seed,
        }
    finally:
        for handle in handles:
            handle.remove()
```

当前文档只要求扰动前向能返回 logits 和调试信息，不在这里计算 NLL。

## 12. 梯度 Top-K 局部扰动

梯度版本需要先对原始输入做一次可反向前向，得到 token 级重要性。当前阶段只实现 token 选择和 mask 生成；指标仍不在这里计算。

### 12.1 捕获视觉 token 梯度

对 projector 输出替换成 requires-grad 的 leaf tensor：

```python
def capture_visual_tokens_hook(trace):
    def hook(_module, _inputs, output):
        leaf = output.detach().requires_grad_(True)
        trace["visual_tokens"] = leaf
        return leaf
    return hook
```

前向后，由后续 NLL 模块产生 scalar loss，再反传：

```python
grad = torch.autograd.grad(loss, trace["visual_tokens"])[0]
visual_scores = grad.norm(dim=-1)  # [B, Nv]
```

如果当前阶段尚未接入 NLL，可先用 smoke loss 验证梯度通路，例如取回答 logits 的某个 scalar，但正式实验必须使用固定回答 teacher-forcing loss。

### 12.2 捕获文本 token 梯度

文本侧同理：

```python
def capture_text_embeddings_hook(trace):
    def hook(_module, _inputs, output):
        leaf = output.detach().requires_grad_(True)
        trace["text_embeddings"] = leaf
        return leaf
    return hook
```

反传后：

```python
grad = torch.autograd.grad(loss, trace["text_embeddings"])[0]
text_scores = grad.norm(dim=-1)  # [B, Seq]
text_scores = text_scores.masked_fill(~text_prompt_mask, float("-inf"))
```

### 12.3 Top-K mask 生成

支持比例和最小数量：

```python
def build_topk_mask(scores: torch.Tensor, ratio: float, min_k: int) -> torch.Tensor:
    if scores.ndim != 2:
        raise ValueError("scores must be [B, N]")
    finite = torch.isfinite(scores)
    valid_count = finite.sum(dim=1)
    masks = torch.zeros_like(scores, dtype=torch.bool)
    for b in range(scores.shape[0]):
        n = int(valid_count[b].item())
        if n == 0:
            continue
        k = max(min_k, round(ratio * n))
        k = min(k, n)
        valid_scores = scores[b].masked_fill(~finite[b], float("-inf"))
        indices = torch.topk(valid_scores, k=k).indices
        masks[b, indices] = True
    return masks
```

局部扰动时将该 mask 写入 `PerturbSpec.token_mask`：

```python
spec = replace(spec, token_mask=visual_topk_mask)
```

## 13. Stage 1：Visual Encoder 输出扰动

Stage 1 位于 vision tower 输出、projector 输入之前。第一版只作为 smoke 功能实现，因为不同 LLaVA / Transformers 版本的 vision tower 输出结构可能不同。

### 13.1 输出结构适配

hook `vision_tower` 后，输出可能是 tensor，也可能是带 hidden states 的对象。实现中需要统一取 tensor：

```python
def extract_vision_tower_tensor(output):
    if torch.is_tensor(output):
        return output
    if hasattr(output, "last_hidden_state"):
        return output.last_hidden_state
    if isinstance(output, (tuple, list)) and torch.is_tensor(output[0]):
        return output[0]
    raise TypeError(type(output))
```

如果 vision tower 输出包含 CLS token，是否扰动 CLS 由配置控制。第一版建议：

```python
PERTURB_STAGE1_CLS = False
```

mask 中排除第一个 token：

```python
if not PERTURB_STAGE1_CLS:
    token_mask[:, 0] = False
```

### 13.2 返回结构保持

如果 hook 输入输出是对象，不能直接返回 tensor 破坏后续 forward。第一版可以暂时只支持输出为 tensor / tuple 的情况；遇到复杂对象直接报错：

```python
if hasattr(output, "last_hidden_state"):
    raise NotImplementedError("stage1 perturbation for structured vision outputs is not enabled yet")
```

Stage 1 稳定后，再补对象重建逻辑。

## 14. Stage 3/4：LLM 中间层扰动预留

Stage 3/4 分别对应 LLM 第 $\lfloor M/3 \rfloor$ 和 $\lfloor 2M/3 \rfloor$ 层输出之后。第一版不强制实现，因为它需要可靠地区分混合序列中的视觉 token span 与文本 token span。

预留函数：

```python
def get_llm_layers(self):
    return self.model.language_model.model.layers

def get_stage_layer_indices(num_layers: int) -> dict[str, int]:
    return {
        "stage3": num_layers // 3,
        "stage4": (2 * num_layers) // 3,

```

Stage 3/4 的关键难点是：进入 LLM 后视觉 token 与文本 token 已经合并成同一个 sequence。必须先记录 image token 展开后的视觉 span，再在 hidden state 上对对应 span 做扰动。

第一版只写接口，不纳入主实验：

```python
def forward_with_llm_layer_perturbation(...):

```

## 15. 批量扰动执行流程

`run_perturb.py` 只负责执行扰动前向并保存中间输出摘要。

单样本流程：

1. 读取样本图像和问题；
2. `prepare_inputs(image, question)`；
3. 原始输入 greedy 生成固定回答；
4. 构造 teacher-forcing 输入；
5. 对视觉侧执行 `NUM_PERTURBATIONS` 次扰动前向；
6. 对文本侧执行 `NUM_PERTURBATIONS` 次扰动前向；
7. 可选：计算梯度 Top-K mask 后再重复第 5、6 步；
8. 保存每次扰动的元信息和 logits 摘要。

`run_perturb.py` 不再保存完整 logits（词表量级、体积过大）。它在扰动前向的同时直接计算每个扰动的标量指标并写入 JSONL：原始前向得到 `nll0`，每个扰动前向得到该扰动的 `nll` 与回答 token 位置的 `KL(p_original || p_perturbed)`。每条样本记录形如：

```json
{
  “id”: “...”,
  “dataset”: “cvbench”,
  “question”: “...”,
  “prediction”: “...”,
  “answer_ids”: [123, 456],
  “prompt_length”: 128,
  “answer_length”: 12,
  “nll0”: 0.832,
  “perturbations”: [
    {
      “stage”: “stage2”,
      “modality”: “vision”,
      “mode”: “norm_isotropic”,
      “sigma”: 0.01,
      “gamma”: 1.0,
      “seed”: 42,
      “nll”: 0.847,
      “kl”: 0.0023
    }
  ]
}
```

下游 `evaluate_perturb_methods.py` 只读取这份 JSONL（不加载模型），按 mode 聚合出每个样本的 `PIS_v/PIS_t`（`mean_k(L_perturbed^k - nll0)`）和 `kl_v/kl_t`，再汇总正确率与 AUROC。两个阶段分离后，扰动前向（贵、需 GPU）只跑一次，评估（便宜、纯 CPU）可反复重跑。

## 18. 单元测试

至少覆盖以下测试：

### 18.1 噪声可复现

同一个 seed、同一个 target shape 生成完全相同的 noise：

```python
noise1 = sample_isotropic_noise(target, seed=42)
noise2 = sample_isotropic_noise(target, seed=42)
assert torch.equal(noise1, noise2)
```

不同 seed 的 noise 应不同：

```python
noise3 = sample_isotropic_noise(target, seed=43)
assert not torch.equal(noise1, noise3)
```

### 18.2 Token mask 正确

```python
target = torch.zeros(1, 4, 8)
mask = torch.tensor([[True, False, True, False]])
spec = PerturbSpec(..., token_mask=mask)
perturbed = perturb_tensor(target, spec)

assert perturbed[:, 1, :].abs().max().item() == 0
assert perturbed[:, 3, :].abs().max().item() == 0
assert perturbed[:, 0, :].abs().max().item() > 0
assert perturbed[:, 2, :].abs().max().item() > 0
```

### 18.3 Hook 清理

连续运行一次扰动前向和一次原始前向，原始前向不应再触发扰动 hook。可以在 hook 中累计计数：

```python
counter = {"n": 0}
# perturb forward 后 counter["n"] == 1
# normal forward 后 counter["n"] 仍为 1
```

### 18.4 文本 mask 不扰动回答 token

构造带 prompt 和 answer 的 embedding 输出，检查 `prompt_length:` 后面的 answer 区域差值为 0。

## 19. 数值与显存注意事项

- 扰动张量使用模型当前 dtype，通常是 `float16` 或 `bfloat16`；
- 扰动前向使用 `torch.inference_mode()`，梯度 Top-K 捕获阶段才使用 `torch.enable_grad()`；
- hook 中不要原地修改 `output`，统一 `output + noise` 返回新 tensor；
- 每次扰动前向后及时释放不需要的 logits，必要时 `torch.cuda.empty_cache()`；
- 不要保存全量 hidden states，除非正在 debug；
- Stage 3/4 暂不进主实验，避免中间层 hook 与 KV cache、attention mask 交互造成隐性错误。

## 20. 当前阶段交付标准

完成扰动实现后，应满足：

1. `run_perturb.py --modes norm_isotropic directional adversarial` 能完成至少 4 条样本 smoke；
2. 视觉扰动只改变 projector 输出的视觉 token；
3. 文本扰动只改变 prompt 文本 token，不改变 image placeholder、padding 和 answer token；
4. 相同 seed 的扰动可复现，不同 seed 的扰动不同；
5. 所有 hook 都能在异常和正常路径下清理；
6. 输出 JSONL 记录每次扰动的 stage、modality、mode、sigma、gamma、seed 和 logits 文件路径；
9. 不在 `run_perturb.py` 中计算 PIS、KL、AUROC 或最终不确定性分数。

当前 `evaluate_perturb_methods.py` 已实现基础比较所需的 teacher-forcing NLL、PIS、回答 token KL 和 AUROC 汇总；若要做最终论文指标，可再单独整理指标计算与评估实现文档。
