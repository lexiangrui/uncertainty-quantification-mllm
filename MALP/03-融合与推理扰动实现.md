# MALP 融合与推理不确定性：当前实现

本文档描述当前生效的两处扰动位置。旧版 projector/text-embedding 分离的
`stage2` 路径已由本方案取代。

## 1. Fusion uncertainty

集群环境 Transformers 5.12.1 的 `LlavaModel.forward()` 先构造文本 embedding，
再用视觉特征替换 image placeholder：

```python
inputs_embeds = self.get_input_embeddings()(input_ids)
image_features = self.get_image_features(...).pooler_output
special_image_mask = self.get_placeholder_mask(...)
inputs_embeds = inputs_embeds.masked_scatter(special_image_mask, image_features)

outputs = self.language_model(inputs_embeds=inputs_embeds, ...)
```

融合扰动精确注入在 `masked_scatter` 之后、`language_model` 之前。实现对
`self.model.model.language_model` 注册 `forward_pre_hook(with_kwargs=True)`，修改
其 `kwargs["inputs_embeds"]`。

扰动 mask 联合选择：

- 展开后的全部 image token；
- 用户问题的精确 token span；
- 排除 chat template、generation prompt、padding 和 teacher-forcing answer token。

因此融合分数测量视觉与问题表示完成融合、尚未进入 LLaMA 推理时的局部稳定性。

## 2. Reasoning uncertainty

推理扰动只作用于 LLaMA 中间层 15--20（零基索引，含首尾）：

```python
REASONING_LAYERS = (15, 16, 17, 18, 19, 20)
```

每个 `LlamaDecoderLayer.forward()` 的相关路径为：

```python
residual = hidden_states
hidden_states = self.input_layernorm(hidden_states)
hidden_states, _ = self.self_attn(...)

# MALP reasoning perturbation：在这里

hidden_states = residual + hidden_states
hidden_states = self.post_attention_layernorm(hidden_states)
hidden_states = self.mlp(hidden_states)
hidden_states = residual + hidden_states
```

实现对以下六个模块分别注册 forward hook：

```python
self.model.model.language_model.layers[layer_index].self_attn
```

hook 只替换 self-attention 返回值中的 attention output，不修改 attention weights、
KV cache 或 residual。扰动后的 attention output 随后进入该层残差连接、MLP 和所有
后续 decoder 层。

六层在同一次 teacher-forcing forward 中都被扰动。随机模式使用
`base_seed + layer_index`，避免六层复用相同噪声；对抗模式在一次反向传播中分别捕获
六层 attention output 的梯度，再在各层沿各自负梯度单位方向扰动。

推理 mask 选择因果上直接预测固定回答 token 的 hidden positions：

```text
prompt 最后一个位置 + 前 L-1 个回答位置
```

这与回答 logits 的 causal shift 完全一致，并排除生成后的 padding。它测量的是
15--20 层 attention 推理结果对固定回答分布的敏感性。

## 3. 扰动与指标

两个 stage 都支持：

- `norm_isotropic`；
- `directional`；
- `adversarial`。

每个 `(stage, mode)` 独立执行 K 次 Monte Carlo 扰动，输出：

```text
PIS(stage, mode) = mean_k(NLL_perturbed - NLL_original)
KL(stage, mode)  = mean_k KL(p_original || p_perturbed)
```

默认 `sigma=0.01`。输出记录的 `stage` 为 `fusion` 或 `reasoning`；reasoning
记录额外保存 `layers: [15, 16, 17, 18, 19, 20]`。

## 4. 选择题答案一致性（新增）

答案一致性流程与上述固定回答 teacher-forcing 流程并行保留。它对每个
`(stage, mode)` 使用 K 个不同随机种子，在扰动生效时重新执行 greedy generation，
再将输出解析为选项字母并计算不确定性。`do_sample=False`，因此答案变化只来自 latent
扰动，而不是解码采样。

当前仅支持选择题数据集 `cvbench` 和 `cvbench2d`，并且只启用：

新增 generation-only 的 `final_hidden` stage：仅在自回归生成的 prompt prefill 首次前向中，在 language model 最终层输出、进入 lm_head 之前，对序列最后一个 hidden-state embedding 扰动一次。后续带 KV cache 的答案解码步骤不再重复扰动。teacher forcing 全程不注入扰动，只分别对原始生成答案和一次扰动后生成答案做普通前向评分。可用 `MALP/cvbench_final_hidden_topk.py` 在 CVBench 测试集取五个样例，输出扰动前后生成文本、生成过程每一步 top-k token/probability，以及无扰动 teacher forcing 的 NLL 与逐 token top-k。

- `norm_isotropic`；
- `directional`。

答案一致性流程不启用 `adversarial`。当前对抗方向依赖固定答案的完整
teacher-forcing 梯度，无法直接与动态长度的 KV-cache 生成路径对齐。

生成阶段的扰动规则为：

- `fusion`：只在 prompt prefill 时扰动图像 token 和用户问题 token，扰动影响通过
  KV cache 传播到后续生成；
- `reasoning`：prefill 时扰动最后一个 hidden position，之后在每个 decode step
  扰动当前 self-attention 输出；不同层、不同 decode step 使用不同的确定性派生种子。

对 K 个扰动答案解析得到类别 $c_1,\ldots,c_K$。无法解析为合法字母的输出保留为
独立的 `INVALID` 类，避免静默丢弃失败生成。设类别 $c$ 的经验频率为 $p_c$，输出：

$$
U_{\mathrm{ent}}=-\frac{\sum_c p_c\log p_c}{\log K},
\qquad
U_{\mathrm{vr}}=1-\max_c p_c,
$$

$$
U_{\mathrm{flip}}=\frac{1}{K}\sum_{k=1}^K\mathbb{1}[c_k\ne c_0],
$$

以及所有扰动答案对的 `pairwise_disagreement`。其中 $c_0$ 为未扰动 greedy
答案。主指标为 `answer_entropy`，其余指标用于解释不一致来源。

GPU 生成：

```bash
python MALP/run_choice_consistency.py \
  --dataset cvbench2d \
  --limit 50 \
  --num-generations 10 \
  --sigma 0.1 \
  --modes norm_isotropic directional \
  --stages fusion reasoning \
  --output results/malp/perturb/cvbench2d_choice_consistency.jsonl
```

CPU 离线评估：

```bash
python MALP/evaluate_choice_consistency.py \
  --input results/malp/perturb/cvbench2d_choice_consistency.jsonl \
  --output results/malp/perturb/cvbench2d_choice_consistency_metrics.jsonl
```

评估汇总按 `(stage, mode, sigma)` 报告各一致性分数的均值，以及在同时存在正确和
错误样本时预测错误的 AUROC。

## 5. 视觉 embedding 的文本 token 近邻解码（新增验证）

为观察视觉 token 在语言模型词嵌入空间中的局部变化，新增脚本
`MALP/visual_embedding_token_decode.py`。脚本提取 LLaVA vision tower 的 patch
特征，经 `multi_modal_projector` 映射到 LLaMA hidden size，得到形状为
`[batch, 576, 4096]` 的视觉 embedding。随后将每个视觉 token 与 LLaMA
`get_input_embeddings().weight` 的完整文本词表计算余弦相似度，分别输出：

- 原始视觉 token 的 top-k 文本 token 近邻；
- 施加 MALP `norm_isotropic` 或 `directional` 扰动后的 top-k 文本 token 近邻；
- token 位置、原始/扰动范数、位移 L2、与原向量余弦相似度。

这里的“文本 token”是**语言模型词嵌入空间的最近邻标签**，不是视觉 embedding
的可逆自然语言解码。视觉 token 并不保证对应某一个真实词，尤其在完整 32,064
词表上，近邻相似度可能较低、token 可能是子词或跨语言片段。因此该实验主要用于
比较同一视觉 token 在扰动前后的局部邻域是否稳定，而不应把 top-1 token 直接解释
为图像中物体的识别结果。若需要验证视觉语义是否保持，应结合视觉问答答案、跨模态
检索或独立 judge，而不能只看 token 标签。

集群 GPU 作业模板为 `slurm/malp/visual_embedding_token_decode.sbatch`。图像需要先
放在集群共享存储路径，再从校外入口提交作业，例如：

```bash
IMAGE=/opt/lexiangrui/datasets/example.jpg \
OUTPUT=/home/lexiangrui/Uncertainty-Quantification-of-MLLM/results/malp/visual_embedding_token_decode.json \
sbatch --export=ALL,IMAGE,OUTPUT,MODE=norm_isotropic,SIGMA=0.01 \
  slurm/malp/visual_embedding_token_decode.sbatch
```

一次实际验证使用 LLaVA-1.5-7B 和一张火车图，成功提取 576 个视觉 token；结果文件为
`results/malp/visual_embedding_token_decode.json`。在 `sigma=0.01` 下，抽样 token 的
原始与扰动后 top-k 近邻大多保持不变，单 token 与原向量余弦约为 `0.99995`。这说明
小半径扰动的局部邻域较稳定，但不代表模型已经把视觉内容编码成可直接阅读的文本。

## 6. 基于 Prompt 的视觉扰动生成验证：Projector 前后对照

直接把单个视觉 token 与文本词表做最近邻只能观察表示空间的形式邻域，不能代表
模型真正生成了什么文本。因此新增生成式实验：对同一个 COCO 图片和同一个 prompt，
分别运行原始输入、**Projector 之前扰动**和**Projector 之后扰动**三次 greedy
generation，直接比较 LLaVA 生成的图片描述。

设视觉编码器输出为 $Z_v$，projector 为 $P$，则两处干预分别为：

$$
\text{pre-projector:}\quad
\widetilde Z_v=\operatorname{Perturb}(Z_v;\sigma),
\qquad H_v=P(\widetilde Z_v),
$$

$$
\text{post-projector:}\quad
H_v=P(Z_v),
\qquad \widetilde H_v=\operatorname{Perturb}(H_v;\sigma).
$$

随后将视觉特征送入同一个 LLaVA prompt：

```text
<image> Describe this image briefly.
```

并保持 `do_sample=False`，使三次描述的差异只来自视觉 embedding 干预，而不是采样
随机性。Projector 前扰动测量视觉编码特征在跨模态映射前的敏感性；Projector 后扰动
测量已经映射到 LLaMA hidden space 的视觉接口对生成结果的敏感性。两者使用相同的
图像、prompt、模型、greedy 解码策略和扰动模式，但使用不同派生 seed。

### 6.1 COCO 五图结果

在 COCO `val2017` 的 5 张图片上，使用 `norm_isotropic` 扰动。先用
`sigma=0.01` 检查局部稳定性，再用 `sigma=0.5` 观察可见变化。

| COCO image id | 原始描述（摘要） | Projector 前，$\sigma=0.5$ | Projector 后，$\sigma=0.5$ |
|---|---|---|---|
| `000000037777` | 厨房、炉灶、水槽、餐桌和橙子 | 厨房、冰箱、微波炉、水槽和烤箱；餐桌椅 | 干净厨房、白色炉灶、水槽和冰箱；餐桌椅、各种水果 |
| `000000087038` | 滑板公园，至少 12 人，多人滑板 | 多名滑板者，其中一人做动作 | 多名滑板者，其中一名男子做动作 |
| `000000174482` | 蓝色自行车、树和街边汽车 | 蓝色自行车、树、左侧汽车、远处车辆和卡车 | 蓝色自行车、树、左侧汽车和背景车辆 |
| `000000252219` | 男子站在购物车旁看手机 | **男子坐在购物车上**，整理衣物 | 男子站在装满物品的购物车旁看手机 |
| `000000397133` | 男子穿白衬衫在厨房准备食物 | 男子穿白围裙，可能在制作披萨 | 男子穿白衬衫在厨房准备食物，周围有锅碗 |

在 `sigma=0.01` 下，5 张图的 Projector 前后描述均与原始 greedy 描述完全一致，
说明该小半径下没有触发离散文本变化。增大到 `sigma=0.5` 后，5 张图在 Projector
前和 Projector 后的描述均发生变化，但变化类型不同：

- Projector 前更容易改变局部视觉细节和物体属性，例如厨房中的设备、是否有卡车，
  以及购物车图中出现“坐在购物车上”的明显错误；
- Projector 后通常保留主体场景，但重写细节、数量或描述措辞，说明 LLaMA 接口层的
  小范围变化会改变后续语言组织；
- 描述改变不一定代表模型真正看错，也可能只是 greedy generation 在接近的候选词
  之间发生离散选择。因此应结合事实性 judge、VQA 答案和 token-level NLL/KL 判断
  变化是合理改写还是幻觉。

本实验统一使用 `--max-new-tokens 256`，避免较长描述在生成上限处被截断。完整输出保存在：

- `results/malp/coco5_visual_prompt_perturb.json`（`sigma=0.01`）；
- `results/malp/coco5_visual_prompt_perturb_sigma05.json`（`sigma=0.5`）。

实现脚本为 `MALP/coco5_visual_prompt_perturb.py`，Slurm 作业为
`slurm/malp/coco5_visual_prompt_perturb.sbatch`。该版本不再输出视觉 token 的文本
词表近邻，而是直接输出模型的原始和扰动后自然语言描述，更适合作为 MALP 语义保持
与生成稳定性的验证。

### 6.2 directional 方法对照结果

在同一批 5 张 COCO 图片、同一 prompt 和 `max_new_tokens=256` 下，进一步加入
`directional` 扰动：

$$
\widetilde v_i=(1+\sigma\alpha_i)v_i,
\qquad \alpha_i\sim\mathcal N(0,1).
$$

`directional` 的两组真实生成结果如下：

| 扰动强度 | Projector 前 | Projector 后 |
|---:|---:|---:|
| `sigma=0.01` | 5/5 描述保持不变 | 5/5 描述保持不变 |
| `sigma=0.5` | 5/5 描述改变，但主要仍是合理场景改写 | 5/5 描述改变，其中部分为空或退化为重复 token |

典型例子是 COCO `000000087038` 滑板公园图：Projector 前扰动仍生成关于滑板公园、
人物和自行车的完整描述；Projector 后扰动则生成大量重复的
`Skate skate skates ...`。另外，厨房、自行车和购物车图片在 Projector 后扰动下
出现空描述，厨房图甚至只输出一个句号。这说明沿原方向的长度缩放在较大 `sigma`
下可能把部分视觉 token 的缩放系数推向不稳定区域，Projector 后的语言接口对此尤其
敏感。

因此，`directional` 的实验结果不能简单解释为“语义保持的长度扰动”。正式扫描时应
记录每个 token 的缩放系数 $1+\sigma\alpha_i$，并至少采用以下约束之一：

- 截断或拒绝 $1+\sigma\alpha_i\le 0$ 的样本，避免向量越过原点；
- 使用较小的 `sigma`，先在 `0.01–0.1` 范围内扫描；
- 将 `directional` 作为长度敏感性对照，将 `norm_isotropic` 作为主要随机方向扰动。

完整结果为：

- `results/malp/coco5_visual_prompt_perturb_directional_sigma001.json`；
- `results/malp/coco5_visual_prompt_perturb_directional_sigma05.json`。

## 7. ViLP 50 样本无扰动内部状态与平均 NLL 基线

为建立后续 MALP 扰动实验的可比基线，新增
`MALP/run_vilp50_original_states_nll.py`，在服务器上直接使用原始 LLaVA-1.5-7B
处理 ViLP 前 50 个样本，不施加任何扰动。ViLP loader 按每个原始问题的 `case1`、
`case2` 顺序展开，因此这 50 条记录对应前 25 个 ViLP 原始问题的事实/反事实图像对。

每条样本执行以下流程：

1. 使用原始图像和问题进行 greedy generation（`max_new_tokens=128`）；
2. 在 Projector 的 `forward_pre_hook` 捕获视觉编码器输出，形状为 `[1,576,1024]`；
3. 在 Projector 的 `forward_hook` 捕获映射后的视觉 embedding，形状为
   `[1,576,4096]`；
4. 固定模型自己生成的 answer ids，进行无扰动 teacher-forcing；
5. 对有效回答 token 计算平均 NLL，并保存逐样本记录。

注意，这里的 NLL 是模型对**自己 greedy 生成的可见回答 token**的平均负对数似然：

$$
\mathcal L_0(x)
=-\frac{1}{L_x}\sum_{t=1}^{L_x}
\log p_\theta(y_t\mid y_{<t},I_x,Q_x),
$$

不是对 ViLP 人工参考答案的 NLL。EOS、padding，以及单独生成的空白 SentencePiece
标记（通常解码为 `▁` 但可见文本为空）均不计入回答内容 NLL。它反映的是模型自身回答的内部置信度基线；如果
要评价参考答案或事实/反事实 case 的正确性，需要另行把 reference answer 作为
teacher-forcing target。

## 8. 高 NLL 错误回答的定向扰动案例

为了检验“模型回答错误但自身置信度较高/较低”与隐空间敏感性是否一致，从上述
ViLP 50 条无扰动记录中先用预测与 reference 的大小写无关字符串匹配筛出错误回答，
再按原始 `mean_nll` 从高到低选取 5 条：

| 样本 | 模型回答 | reference | 原始 mean NLL |
|---|---|---|---:|
| `vilp-17-case2` | 8 | 10 | 0.919914 |
| `vilp-3-case2` | Square | Cubical | 0.896934 |
| `vilp-2-case2` | Round | Circle | 0.810530 |
| `vilp-0-case2` | 4 | 6 | 0.790965 |
| `vilp-1-case1` | Hexagon | Sphere | 0.781740 |

对这 5 条样本使用 `norm_isotropic`、`sigma=0.1`，分别在 Projector 前和 Projector
后进行一次生成式扰动；同时固定原始回答进行 teacher-forcing，计算扰动后的原回答
NLL 与原始 NLL 的差值：

| 样本 | Projector 前描述 | 前 ΔNLL | Projector 后描述 | 后 ΔNLL |
|---|---|---:|---|---:|
| `vilp-17-case2` | 8 | −0.004572 | 8 | −0.000775 |
| `vilp-3-case2` | Square | +0.004516 | Square | +0.011999 |
| `vilp-2-case2` | Round | −0.006238 | Round | −0.009258 |
| `vilp-0-case2` | 4 | +0.000738 | 4 | −0.007178 |
| `vilp-1-case1` | Cube | +0.001510 | Octagon | +0.001441 |

结果有两个值得注意的现象：

1. 前 4 个样本虽然回答错误且原始 NLL 较高，但在 `sigma=0.1` 的小扰动下描述仍
   保持不变，原回答 NLL 增量也很小，说明“错误回答的 NLL 高”并不自动意味着对
   局部视觉表示扰动敏感；
2. `vilp-1-case1` 的生成答案发生了离散翻转（Hexagon → Cube/Octagon），但固定原
   回答的 ΔNLL 仍仅约 +0.0015，说明生成决策边界变化与固定序列置信度变化可以不同步。

因此，高 NLL 错误样本不能只按单点 NLL 判断其不确定性来源。后续应在多个 sigma、
多个随机方向下同时观察 PIS/KL、答案翻转率和独立幻觉标签；完整案例结果保存于
`results/malp/vilp5_high_nll_wrong_sigma01.json`，脚本为
`MALP/run_vilp5_high_nll_wrong_perturb.py`。

## 9. Projector 后视觉 Embedding 扰动半径扫描

`MALP/run_visual_embedding_sweep.py` 专门实现“纯视觉、Projector 后、随机范数
保持扰动”。它与主流程的 `fusion` 探针不同：扰动 hook 直接注册在
`multi_modal_projector` 输出，因此不会扰动问题 token 的文本 embedding。

对于每个随机种子，所有 `sigma` 复用同一个高斯随机方向，只逐步增大半径；
这样半径曲线反映的是强度变化，而不是各扫描点重新抽样方向带来的混淆。
每个 `(sigma, seed)` 同时记录：

- greedy 重生成答案及是否相对原答案翻转；
- 固定原答案的 NLL、`delta_nll` 与 token 分布 KL；
- 实际平均相对 L2 半径、余弦相似度和范数保持误差。

样本级不确定性输出包含每个 `sigma` 的翻转率/NLL/KL 曲线、各随机方向的
首次翻转半径、未翻转的右删失种子，以及 `flip_auc`、`kl_auc` 和
`abs_delta_nll_auc`。`flip_auc` 越高、首次翻转半径越小，表示局部稳定
区域越小、不确定性越高。未翻转方向作为右删失而不是被丢弃；若扫描范围内不足
一半方向翻转，`median_first_flip_sigma` 为 `null`，表示中位决策边界位于最大扫描
半径之外。

本地/集群命令示例：

```bash
python MALP/run_visual_embedding_sweep.py \
  --dataset cvbench2d --limit 20 --num-directions 5 \
  --sigmas 0.05 0.1 0.25 0.5 0.75 1.0 1.5 2.0 \
  --output results/malp/visual_embedding_sweep/cvbench2d.jsonl

sbatch --export=ALL,DATASET=cvbench2d,LIMIT=20,NUM_DIRECTIONS=5 \
  slurm/malp/run_visual_embedding_sweep.sbatch
```
