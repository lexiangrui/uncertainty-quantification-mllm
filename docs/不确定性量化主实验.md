# 不确定性量化主实验

## 1. 数据集

三个数据集均使用 Hugging Face 发布的完整评测数据，不进行抽样或重新划分训练/测试集。样本数统一按实际送入模型的“问题实例”计数，不按图像数计数。三个数据集共包含 2,247 个问题实例；三个模型在完全相同的问题清单上评测，共得到 6,741 个“问题—模型”主响应实例。

| 数据集（Hugging Face） | 问题实例数 | 数据与任务类型 | 本实验答案类型 | 主要分析对象 |
|---|---:|---|---|---|
| [ViLP](https://huggingface.co/datasets/ViLP/ViLP) | 900 | 300 个不同问题，每题配 3 组图像—答案，构成 900 个 QIA 实例 | 官方答案通常为单词；本实验允许选项、数值、词语、短语或短句 | 语言先验与事实/反先验视觉证据的冲突 |
| [HallusionBench](https://huggingface.co/datasets/lmms-lab/HallusionBench) | 1,129 | 951 个 image 问题与 178 个 non-image 问题；含 VD/VS 及问题组 | 根据原题输出 Yes/No、短语或短句 | 视觉错觉、语言先验、错误前提及图文冲突 |
| [MM-Vet](https://huggingface.co/datasets/lmms-lab/MMVet) | 218 | 单图开放式视觉问答，覆盖六类核心能力及其组合 | 词语、数字、列表、短句或说明性自由文本 | 开放回答中的视觉事实错误、知识错误与复合能力失败 |

这里的 ViLP “900”指 900 个实际评测的 Question–Image–Answer 三元组，而不是 300 个去重后的问题文本；HallusionBench “1,129”是两个官方 split 的问题数之和 \(951+178\)。

### 1.1 ViLP

ViLP 用于检验视觉语言模型是否会被问题文本诱导的语言先验支配。Hugging Face 数据包含 300 个不同问题，每个问题对应三张图像和三个配对答案：一个 Prior Answer 和两个要求结合文本与视觉证据才能得到的 Test Answer，共形成 900 个 QIA 问题实例。本实验展开全部三组配对，每个 QIA 都作为独立推理实例；在分组统计和 bootstrap 时仍以原始问题 ID 聚类，避免把同题的三组实例视为完全独立。

### 1.2 HallusionBench

HallusionBench 包含 1,129 个问题实例：`image` split 951 个，`non_image` split 178 个。数据覆盖 Visual Dependent、Visual Supplement、language hallucination、visual illusion 及关联问题组，GT 主要为 Yes/No，并提供 `gt_answer_details`。本实验使用两个 split 的全集；对 `non_image` 或 `visual_input=0` 的实例不额外传入图像。

### 1.3 MM-Vet

MM-Vet 的 `test` split 包含 218 个问题，每题对应一张图像和一个开放式参考答案，综合覆盖 recognition、OCR、knowledge、spatial awareness、language generation 和 math 六项能力及其组合。参考答案可能是词语、数字、列表、短句或说明性描述。

### 1.4 统一正确率、幻觉率与标签关系

正确性与幻觉由同一次 LLM Judge 调用输出，但作用于不同字段并作为两个独立标签保存：正确性 \(C\) 只评价最终答案部分，幻觉 \(H\) 只评价视觉观察与推理部分。三个数据集共用同一套判定原则，仅在 GT 来源和个别边界上按数据集细化。

三个数据集均允许以下四种标签组合：

| \(C\) | \(H\) | 含义 |
|---:|---:|---|
| 1 | 0 | 最终答案正确，视觉观察/推理无幻觉 |
| 1 | 1 | 最终答案正确，但视觉观察/推理含幻觉 |
| 0 | 0 | 最终答案错误，但视觉观察/推理无幻觉 |
| 0 | 1 | 最终答案错误，且视觉观察/推理含幻觉 |

统一定义：

\[
\mathrm{Accuracy}=\frac{1}{N}\sum_i C_i,\qquad
\mathrm{Hallucination\ Rate}=\frac{1}{N}\sum_i H_i.
\]

## 2. 测试模型

选择三个可在本地部署、能够访问生成 token logits 与最后层隐藏状态的开源多模态大模型：

| 模型（Hugging Face） | 精确模型标识 | 参数结构 | 选择理由 |
|---|---|---|---|
| [LLaVA-1.5-7B](https://huggingface.co/llava-hf/llava-1.5-7b-hf) | `llava-hf/llava-1.5-7b-hf` | 约 7B 稠密模型 | Transformers 格式的经典开源视觉语言基线 |
| [Qwen2.5-VL-7B-Instruct](https://huggingface.co/Qwen/Qwen2.5-VL-7B-Instruct) | `Qwen/Qwen2.5-VL-7B-Instruct` | 约 7B 稠密模型 | Qwen 官方开源 checkpoint，OCR 与视觉推理能力较强 |
| [InternVL3.5-8B-HF](https://huggingface.co/OpenGVLab/InternVL3_5-8B-HF) | `OpenGVLab/InternVL3_5-8B-HF` | 约 8B 稠密模型 | 原生 Hugging Face 多模态 checkpoint，作为与 LLaVA、Qwen 系列不同的第三种模型架构 |

### 2.1 三模型输出格式 LoRA 适配

前期指令遵循测试表明，被测模型在 greedy 和随机采样时均可能出现标签遗漏、标签不闭合、顺序错误和 XML 外续写。由于后续 UQ 与 Judge 必须可靠区分视觉证据、推理和最终答案，本实验分别对 LLaVA-1.5-7B、Qwen2.5-VL-7B-Instruct 和 InternVL3.5-8B-HF 进行只针对回答组织方式的 LoRA 监督微调。该阶段不使用三个正式评测集中的任何样本。

#### 2.1.1 训练数据来源与划分

训练数据仅来自官方 VQAv2 train2014。根据人工标注答案筛选一致度较高、答案非空且简短的样本，并兼顾不同问题类型。初始规模固定为 2,000 条：

| Split | 样本数 | 用途 |
|---|---:|---|
| Train | 1,600 | LoRA 参数更新 |
| Validation | 200 | 监测验证 loss 与选择 checkpoint |
| Held-out format test | 200 | 只用于最终格式遵循与答案保持评测 |

数据集按图像划分三个 split，保证同一图片不会跨 split。ViLP、HallusionBench 和 MM-Vet 完全不进入 LoRA 数据构造，以避免正式评测泄漏。

#### 2.1.2 Qwen3.7-Plus 多模态教师数据构造

机械模板无法可靠描述开放图像中的真实证据，因此使用 `qwen3.7-plus` 作为多模态教师。教师同时接收真实 COCO 图像、VQAv2 问题、人工多数答案以及少量人工编写的高质量示例，生成回答问题所需的视觉证据、简短推理和最终答案。

教师数据遵循以下质量原则：

- 视觉部分只描述回答问题所需且在图像中可见的证据；
- 推理部分简短连接视觉证据与答案，不引入图像不支持的事实；
- 最终答案与 VQAv2 人工多数答案保持一致；
- 三个部分内容明确分离，并统一转换为 `<vision>`、`<reasoning>`、`<answer>` 三段 XML 监督格式；
- 对答案不一致、内容缺失、格式异常或包含元数据泄漏的样本予以剔除，不以机械模板补齐。

在批量构造前先抽取少量真实样本进行人工核对，确认教师生成的视觉证据与原图一致、推理合理且答案正确后，再扩展到完整的 2,000 条数据。

#### 2.1.3 LoRA 训练配置

三个基础权重分别为 `llava-hf/llava-1.5-7b-hf`、`Qwen/Qwen2.5-VL-7B-Instruct` 和 `OpenGVLab/InternVL3_5-8B-HF`。每个模型分别训练独立 adapter，三者使用完全相同的数据划分、目标回答和优化超参数。训练冻结视觉编码与多模态对齐部分，仅使用 LoRA 调整语言模型的 attention projection，使其学习稳定的三段式内容组织与 XML 输出格式，同时尽量保持原有视觉问答能力。初始实验采用较小 LoRA rank、单轮训练和较低学习率，并根据验证集表现决定是否增加训练强度。

训练只监督模型生成的目标回答，不将图像和用户指令作为预测目标。验证集用于监测格式学习和答案能力是否退化，避免模型仅记忆固定标签或过拟合训练措辞。

#### 2.1.4 格式适配验收与正式实验边界

每个模型都在同一组 200 条 held-out format test 上分别报告完整 XML 合法率、标签顺序正确率、标签重复率、XML 外额外文本率、最终答案准确率，以及视觉描述的人工抽样一致性。LoRA 不能只以训练 loss 验收；只有在格式遵循显著提高且答案能力没有明显下降时，该模型的 adapter 才用于后续正式实验。

LoRA 会改变生成分布，即使其主要目标是格式适配。因此正式实验必须对三个模型分别固定并记录“基础权重 + LoRA adapter”这一完整版本；不得将任一 base 模型与 LoRA 模型的回答或 UQ 分数混在同一模型组中。若需要判断格式微调是否改变任务能力，应将对应 base 模型作为单独消融组，在同一问题清单上独立报告。

三个模型统一采用：

- greedy 主回答：`do_sample=false`，`temperature=0`；
- UQ 随机采样：`do_sample=true`，`temperature=1.0`，不显式传入 `top_p` 或 `top_k`；
- 每个输入采样 \(K=5\) 个回答；

Semantic Entropy 与 UMPIRE 共用上述同一批随机采样回答，避免重复推理和采样差异。Perplexity 对 greedy 主回答进行 teacher-forced 概率计算。

## 3. 回答 Prompt、输出规范与统一 LLM Judge

### 3.1 测试模型回答指令

回答内容参考 VL-Calibration（arXiv:2604.09529v1）附录 B 的分解思路：先描述视觉观察，再进行逻辑推理，最后给出正式答案。三个部分必须能够被稳定分离，以便正确性 Judge 只评价最终答案、幻觉 Judge 只评价视觉观察和推理，并使 UQ 方法统一作用于最终答案部分。

三个被测模型在正式实验中统一采用与格式 LoRA 目标一致的 XML 协议。回答必须仅包含以下三个标签，每个标签恰好出现一次并按固定顺序排列；标签之间不换行，标签外不输出任何文本：

```text
<vision>Relevant visual evidence.</vision><reasoning>Brief reasoning based on the evidence.</reasoning><answer>Concise final answer.</answer>
```

`<vision>` 只记录回答当前问题必需且可从图像中观察到的证据；`<reasoning>` 只记录从证据到答案的简短推导；`<answer>` 只记录简洁的最终答案。不为任何模型设置自然语言标题等替代协议，格式解析失败作为实验结果显式统计。

### 3.2 测试模型 User Prompt 与输出

```text
[Image]
{official_image}

[Question]
{official_question}

[Response requirements]
Answer using exactly these three XML tags once and in order, with no line breaks
and no text outside them: <vision>relevant visible evidence</vision><reasoning>brief
reasoning</reasoning><answer>concise final answer</answer>
```

回答指令、图像和问题放在同一条 user message，不创建 system message。该设计来自 LLaVA-1.5 的单变量 role 消融：相同提示位于 system role 时三部分可分率为 0/11，移入 user message 后为 11/11。为使微调与正式测试的条件一致，上述指令的措辞和单行 XML 模板在三个模型间保持不变。正式实验必须保存原始回答、解析后的三个部分、Prompt 版本和格式解析状态；解析失败的样本不得静默修复，而应单独统计并按预先规定的失败策略处理。



### 3.4 LLM Judge System Prompt

三个数据集的每条 greedy 主回答均调用一次 LLM Judge。裁判模型采用 GPT-5.4，并在正式运行前固定具体版本。该步骤同时输出两类标签：

1. **幻觉标签**：参考 LLaVA-RLHF 使用的幻觉评分方式，评价视觉观察与推理部分是否包含图像、问题或 GT 不支持的事实；
2. **正确性**：只比较最终答案部分与数据集 GT，判断最终答复是否语义一致，不用前两部分替答案纠错。

幻觉量表保留完整 0–6 档定义，并采用相同阈值：`rating < 3` 表示存在幻觉，`rating >= 3` 表示无幻觉。

固定提示如下：

```text
You are an impartial judge for a multimodal response organized into visual
observations, reasoning, and a final answer.

Task 1: Hallucination
Judge hallucination only from the visual observations and reasoning parts. Multimodal
hallucination means content inconsistent with the image, question, context, or
facts; it is not the same as every error. Calculation mistakes, flawed reasoning,
or wrong formulas are usually general/reasoning errors. Fabricating nonexistent
objects, attributes, relations, numbers, conditions, evidence, or introducing
unsupported premises/rules/facts is hallucination.

Use the full 0-6 scale:
- Rating 6: very informative with good analysis or reasoning, no hallucination.
- Rating 5: very informative, no hallucination.
- Rating 4: somewhat informative, no hallucination.
- Rating 3: not informative, no hallucination.
- Rating 2: very informative, with hallucination.
- Rating 1: somewhat informative, with hallucination.
- Rating 0: not informative, with hallucination.

The hallucination label MUST follow this threshold:
- rating 0, 1, or 2 => hallucination=true.
- rating 3, 4, 5, or 6 => hallucination=false.

If hallucination=true, hallucination_types must be "vision_hallucination" for
false visual observations, "reasoning_hallucination" for unsupported reasoning
claims, or both.


Task 2: Correctness
Judge correctness only from the final answer part. Compare it with the ground
truth provided in the user prompt.

```

## 4. 三种不确定性量化方法

三种方法均规定“分数越高表示不确定性越高”，且正式检测对象统一为最终答案部分的内容。

### 4.1 Perplexity

**Perplexity（PPL）**是语言模型中常用的序列概率不确定性度量（例如 [Bengio et al., 2003](https://www.jmlr.org/papers/v3/bengio03a.html)），用模型对其已生成答案的条件概率衡量预测不确定性。给定图文问题及提示组成的条件输入 \(q\)，设最终答案部分的 token 序列为 \(y=(w_1,\ldots,w_N)\)。自回归模型给出的序列概率为

\[
p_M(y\mid q)=\prod_{j=1}^{N}p_M(w_j\mid q,w_{<j}).
\]

其长度归一化负对数似然（NLL）与困惑度分别为

\[
\operatorname{NLL}(y\mid q)=-\frac{1}{N}\sum_{j=1}^{N}
\log p_M(w_j\mid q,w_{<j}),
\qquad
\operatorname{PPL}(y\mid q)=\exp\!\left(\operatorname{NLL}(y\mid q)\right).
\]

PPL 是 token 层面的局部不确定性：若模型在给定前缀下普遍只赋予实际答案 token 较低概率，则 PPL 较高，表示该答案在模型自身预测分布下较不典型、置信度较低。它不比较多次生成的语义是否一致，也不会区分“不同措辞”与“不同含义”；因此它构成本实验的单回答概率基线。

工程实现直接使用 greedy 生成时最终答案区间的自回归 token log probability；这与将同一已生成序列固定后执行 teacher forcing 得到的条件概率数学等价，同时避免重复前向。正式结果只保存 PPL、mean NLL 和答案 token 数。

### 4.2 Semantic Entropy

**Semantic Entropy（语义熵）**将不确定性定义在“回答含义”而非表面 token 序列上，旨在避免把“Paris”“It is Paris”和“France's capital is Paris”这类同义表述误当作相互矛盾的答案。[Farquhar et al., 2024](https://www.nature.com/articles/s41586-024-07421-0) 首先从 \(p_M(\cdot\mid q)\) 采样 \(K\) 个最终答案 \(y_1,\ldots,y_K\)，再按语义等价关系将它们划分为簇 \(\mathcal C=\{c_1,\ldots,c_m\}\)。原文以**相对于问题上下文的双向蕴含**操作化语义等价：仅当 \(y_a\) 蕴含 \(y_b\) 且 \(y_b\) 蕴含 \(y_a\) 时，二者才归入同一簇。

理论上，一个语义簇的概率是簇内所有同义序列概率之和：

\[
p(c\mid q)=\sum_{y\in c}p_M(y\mid q),
\qquad
p_M(y\mid q)=\prod_{j=1}^{|y|}p_M(w_j\mid q,w_{<j}).
\]

语义熵定义为语义簇分布的 Shannon 熵：

\[
\operatorname{SE}(q)=-\sum_{c\in\mathcal C}p(c\mid q)\log p(c\mid q).
\]

实际只能观察有限个采样回答，故原文对已出现的簇以其概率质量归一化后估计该式；若只使用采样频率，则离散近似为

\[
\widehat p(c\mid q)=\frac{1}{K}\sum_{i=1}^{K}\mathbb{I}(y_i\in c),
\qquad
\widehat{\operatorname{SE}}(q)=-\sum_{c\in\mathcal C}\widehat p(c\mid q)\log\widehat p(c\mid q).
\]

当采样回答集中于一个或少数几个语义簇时，语义熵低；当模型在多个彼此不同的答案含义之间分散时，语义熵高。因此，该方法测量的是模型对“答案应表达何种含义”的不确定性，而不是对同一含义不同措辞的偏好。

本工程在每条回答生成完成时从瞬时原始 logits 提取最终答案逐 token log probability，并在内存中计算不确定性；不把内部状态或 token 概率持久化。为减弱回答长度对有限样本概率质量的直接支配，先计算每条采样答案的长度归一化 log probability

\[
\ell_i=\frac{1}{|y_i|}\sum_j\log p_M(w_{i,j}\mid q,w_{i,<j}),
\qquad
\tilde p_i=\frac{\exp(\ell_i)}{\sum_k\exp(\ell_k)},
\]

再令 \(p(c)=\sum_{i:y_i\in c}\tilde p_i\) 代入语义熵。该实现不同于只按簇内采样次数计算的频率熵；正式结果保存最终分数、语义簇划分和簇概率质量，不保存原始 logits、token probability 或 hidden states。

### 4.3 UMPIRE

**UMPIRE**（*Uncertainty using Model Probability Indicators and Response Embeddings*）由 [Lau et al., 2026](https://arxiv.org/abs/2602.24195) 提出。它把两类信号合并为一个训练无关的多模态不确定性分数：

1. **全局语义多样性**：采样回答在模型内部语义/多模态表征空间中是否分散；
2. **局部多模态不一致性**：模型对每个回答在给定图文输入下的条件概率是否低。

对同一输入 \(q\) 的 \(K\) 个采样最终答案 \(y_i\)，依据论文和作者官方代码，令 \(\phi_i\in\mathbb{R}^d\) 为被测 MLLM 最后一层在最终回答 token 处提取并 \(\ell_2\) 归一化后的回答表征，\(\Phi=[\phi_1^\top;\ldots;\phi_K^\top]\in\mathbb{R}^{K\times d}\)。回答的模型条件概率及其不一致度定义为

\[
p_i=p_M(y_i\mid q)=\prod_{j=1}^{|y_i|}p_M(w_{i,j}\mid q,w_{i,<j}),
\qquad
c_i=\exp\!\bigl(\alpha(1-p_i)\bigr),
\]

其中 \(\alpha\geq0\) 控制不一致度项的权重；\(p_i\) 越低，表示该回答越不受模型自身给定的全部输入模态支持，因而 \(c_i\) 越大。令 \(C=\operatorname{diag}(c_1,\ldots,c_K)\)，\(\epsilon>0\) 为保证数值非退化的微小常数，则 UMPIRE 的不确定性为

\[
\operatorname{UMPIRE}(q)=\frac{1}{2K}\log\det\!\left[C\left(\Phi\Phi^\top+\epsilon I_K\right)C\right].
\]

其中 \(\det(\Phi\Phi^\top)\) 对应回答表征张成的平方体积：回答含义越分散，语义体积越大；左、右乘的 \(C\) 又会放大低条件概率（即模型内部认为更不连贯）的回答。该式可精确分解为

\[
\operatorname{UMPIRE}(q)=
\underbrace{\frac{1}{2K}\log\det\!\left(\Phi\Phi^\top+\epsilon I_K\right)}_{\text{语义体积}}
+
\underbrace{\frac{\alpha}{K}\sum_{i=1}^{K}(1-p_i)}_{\text{平均不一致度}}.
\]

故 UMPIRE 同时对“模型给出多种相距较远的答案”以及“回答变化不大但模型对这些回答普遍缺乏内部支持”给出高分；后者是仅依赖回答间语义离散度的方法可能漏检的情形。

复现使用作者官方入口的 `jitter=1e-8`。官方模型包装器以 `compute_transition_scores(..., normalize_logits=True)` 取得实际生成 scores 下的序列概率，因此 UMPIRE 的 \(p_i\) 对齐 temperature 等生成处理后的采样分布；PPL 与本工程 Semantic Entropy 使用处理前原始模型 logits，二者不得混称。作者代码的正式分数保留未归一化尺度 `logdet + alpha * sum(1-p_i)`，自适应 alpha 在每个无标签“模型 × 数据集”运行内取 `abs(median(logdet)/median(sum(1-p_i)))`。工程的 `score` 对齐这一官方口径，同时另存上述论文归一化分解项用于解释。所有 hidden vector 和 token probability 只在内存中存在，结果文件只保存分量、alpha 与最终分数。

自适应 alpha 必须由完整无标签运行估计，不能由单个 smoke 样本确定。单样本时该比例会使两个分量恰好相抵，最终分数约为零，不具有跨样本排序意义。

## 7. 性能评估指标

记第 \(i\) 个问题—模型主回答的正确性和幻觉标签分别为 \(C_i\in\{0,1\}\) 与 \(H_i\in\{0,1\}\)，并定义答案错误标签 \(E_i=1-C_i\)。所有指标在每个“模型 × 数据集”组合内独立计算；不将不同模型或数据集的原始不确定性分数直接合并比较。

### 7.1 基础指标

基础指标评价主回答本身，不使用不确定性分数。每个模型 × 数据集报告：

\[
\mathrm{Accuracy}=\frac{1}{N}\sum_{i=1}^{N}C_i,
\]

\[
\mathrm{Hallucination\ Rate}=\frac{1}{N}\sum_{i=1}^{N}H_i.
\]

其中 Accuracy 衡量最终答案与 GT 的一致性，Hallucination Rate 衡量视觉观察或推理部分是否存在不受图像、问题或 GT 支持的陈述；两者对应独立标签，允许同一样本同时正确且有幻觉，或错误但没有幻觉。

### 7.2 不确定性指标

记 \(q_i\) 为第 \(i\) 个图文问题及其提示，\(y_i\) 为 greedy 主回答的最终答案部分，\(y_{i,1},\ldots,y_{i,K}\) 为 \(K=5\) 个随机采样最终答案（与 §2.1.4 一致）。每种方法对每个实例只输出下表中的一个最终不确定性分数 \(s_i\)，且均按“分数越高，不确定性越高”解释。

| 方法 | 最终不确定性指标 | 指标含义 |
|---|---|---|
| Perplexity | \(s_i^{\mathrm{PPL}}\) | greedy 主回答的长度归一化困惑度 |
| Semantic Entropy | \(s_i^{\mathrm{SE}}\) | 采样回答的概率质量在双向蕴含语义簇间的熵 |
| UMPIRE | \(s_i^{\mathrm{UMPIRE}}\) | 经模型内部不一致度调整的采样回答语义体积 |

三种最终指标的计算式为：

\[
s_i^{\mathrm{PPL}}
=\exp\!\left[-\frac{1}{|y_i|}\sum_{j=1}^{|y_i|}
\log p_M(w_{i,j}\mid q_i,w_{i,<j})\right].
\]

\[
\widetilde p_{i,r}
=\exp\!\left[\frac{1}{|y_{i,r}|}\sum_{j=1}^{|y_{i,r}|}
\log p_M(w_{i,r,j}\mid q_i,w_{i,r,<j})\right],
\qquad
\widehat P(c\mid q_i)
=\frac{\sum_{r=1}^{K}\widetilde p_{i,r}\mathbb{I}(y_{i,r}\in c)}
{\sum_{r=1}^{K}\widetilde p_{i,r}},
\]

\[
s_i^{\mathrm{SE}}
=-\sum_{c\in\mathcal C_i}\widehat P(c\mid q_i)
\log\widehat P(c\mid q_i).
\]

\[
p_{i,r}=p_M(y_{i,r}\mid q_i),
\qquad
C_i=\operatorname{diag}\!\left(
\exp(\alpha(1-p_{i,1})),\ldots,
\exp(\alpha(1-p_{i,K}))
\right),
\]

\[
s_i^{\mathrm{UMPIRE}}
=\frac{1}{2K}\log\det\!\left[
C_i\left(\Phi_i\Phi_i^\top+\epsilon I_K\right)C_i
\right].
\]

其中 \(\mathcal C_i\) 由相对于问题上下文的双向蕴含聚类得到；\(\Phi_i\) 的每一行是一个 \(\ell_2\) 归一化的采样回答表征。

### 7.3 性能评估指标

性能评估考察不确定性分数能否把不可靠回答排在可靠回答之前。对任一二元目标标签 \(Z_i\in\{E_i,H_i\}\)，均将 \(Z_i=1\) 视为正类，并以相同的 \(s_i\) 计算 AUROC、AUPRC 和 PRR：

- **错误检测**：\(Z_i=E_i=1-C_i\)。这是与最终答案不确定性定义直接对应的主要评估；
- **幻觉检测**：\(Z_i=H_i\)。这是面向幻觉检测的次要评估，与第 8 节提取的过度自信/自信不足子集直接相关。由于 \(H_i\) 仅评价视觉观察与推理部分，而三种分数只由最终答案计算，结果应解释为答案不确定性对推理/视觉幻觉的代理预测能力，而非直接对幻觉文本的测量。

| 指标 | 计算与解释 | 优劣方向 |
|---|---|---|
| AUROC | ROC 曲线由不同阈值 \(\tau\) 下的 TPR 与 FPR 构成，衡量随机正类的 \(s_i\) 高于随机负类的概率。 | 越高越好；随机排序为 0.5。 |
| AUPRC | 精确率—召回率曲线下面积；随机基线为当前评估子集的正类比例，适合错误或幻觉类别不平衡的情形。 | 越高越好。 |
| PRR | Prediction Rejection Ratio。按照 \(s_i\) 从高到低拒绝回答，考察不同拒绝率下保留回答的 precision；以随机拒绝与 oracle 拒绝的曲线面积归一化。 | 越高越好；随机为 0，oracle 为 1。 |

1. **AUROC**：ROC 曲线由阈值 \(\tau\) 下的

   \[
   \operatorname{TPR}(\tau)=\Pr(s_i\geq\tau\mid Z_i=1),
   \qquad
   \operatorname{FPR}(\tau)=\Pr(s_i\geq\tau\mid Z_i=0)
   \]

   构成。AUROC 是该曲线下面积，也等价于随机抽取一个正类和一个负类时，正类获得更高不确定性分数的概率：

   \[
   \operatorname{AUROC}=\Pr(s^+>s^-)+\tfrac12\Pr(s^+=s^-).
   \]

   值越接近 1，说明该方法越能将错误或幻觉实例排在前面；0.5 表示随机排序。

2. **AUPRC**：精确率—召回率曲线在每个 \(\tau\) 处使用
   \[
   \operatorname{Precision}(\tau)=\frac{\operatorname{TP}(\tau)}{\operatorname{TP}(\tau)+\operatorname{FP}(\tau)},
   \qquad
   \operatorname{Recall}(\tau)=\operatorname{TPR}(\tau),
   \]

   并报告曲线下面积。其随机基线等于该评估子集的正类比例 \(\frac1N\sum_i Z_i\)，故尤其适用于幻觉或错误比例较低的组合。

3. **PRR（Prediction Rejection Ratio）**：将样本按 \(s_i\) 从高到低依次拒绝；对每个拒绝率 \(r\)，以未被拒绝样本的可靠性 \(1-Z_i\) 计算保留精确率 \(\operatorname{Prec}_{s}(r)\)，并得到 rejection–precision 曲线面积 \(A_s\)。令 \(A_{\mathrm{rand}}\) 和 \(A_{\mathrm{oracle}}\) 分别为随机拒绝和先拒绝所有 \(Z_i=1\) 样本的 oracle 策略的曲线面积，则
   \[
   \operatorname{PRR}=
   \frac{A_s-A_{\mathrm{rand}}}
   {A_{\mathrm{oracle}}-A_{\mathrm{rand}}}.
   \]

   该归一化衡量不确定性排序相对于随机拒绝可实现的有效拒绝增益，并消除不同数据集正类比例对曲线面积的直接影响。PRR 越高越好；随机策略为 0，oracle 为 1。

若某个“模型 × 数据集 × 目标”组合只含一个类别，则 AUROC、AUPRC 和 PRR 无定义，记为 N/A，不以插补值替代。所有点估计均报告以原始问题 ID 为聚类单位的 95% bootstrap 置信区间；对 ViLP，三条 QIA 实例必须随其原始问题 ID 一同重采样。

## 8. 下一步研究方向

主实验完成后，下一步将在模型独立的低不确定性幻觉子集上改进不确定性量化方法，使其能够识别现有 PPL、Semantic Entropy 和 UMPIRE 难以发现的低不确定性幻觉。

每个模型的困难子集固定包含 200 条低不确定性幻觉正例和 200 条三维 baseline 百分位最近邻匹配的非幻觉负例。方法设计、分数方向和超参数应先在开发模型或开发数据上确定，再冻结到其他模型和数据集进行验证；最终同时报告困难子集与完整测试集的 AUROC、AUPRC、PRR 和 group-level bootstrap 置信区间。

本阶段不指定具体改进算法，仓库中也不保留此前扰动、替换或组合方案的实现。具体方法将在下一阶段重新设计与验证。
