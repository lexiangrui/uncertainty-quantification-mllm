# 下一步研究方向：面向低不确定性幻觉的不确定性量化改进

## 1. 方向定位

当前仓库已经完成三种基线不确定性量化方法（Perplexity、Semantic Entropy、UMPIRE）的主实验，并构造了每个模型独立的低不确定性幻觉评测子集。

下一步研究方向确定为：

> 在低不确定性幻觉子集上改进多模态大模型的不确定性量化方法，使新的不确定性分数能够识别现有方法难以发现的低不确定性幻觉。

本阶段暂不预设具体改进算法。此前探索过的隐空间扰动、注意力区域替换及其组合均不作为当前正式方案，相关实现已从仓库删除。

## 2. 目标问题

现有方法可能把部分幻觉样本判为低不确定性：

- 模型对错误答案仍赋予较高 token 概率；
- 多次采样可能稳定地产生语义一致的错误答案；
- 采样回答的内部表征可能高度集中。

因此，下一步方法不能只在完整测试集上提高总体指标，还应专门改善对这些低不确定性幻觉样本的排序能力。

## 3. 固定评测基础

每个模型使用独立的 400 条评测子集：

- 正类：200 条低不确定性幻觉样本；
- 负类：200 条在 PPL、SE、UMPIRE 三维百分位空间中最近邻匹配的非幻觉样本；
- 三种 baseline 在子集上的 AUROC 均接近 0.5。

子集定义、提取流程和统计结果见 [低不确定性子集提取说明.md](低不确定性子集提取说明.md)。

## 4. 后续方法要求

后续提出的改进方法应满足：

1. 明确说明它测量的对象为何是不确定性或幻觉风险，而不是一般视觉依赖程度；
2. 在开发模型或开发数据上确定方法、方向和超参数，再冻结到其他模型和数据集验证；
3. 与 PPL、SE、UMPIRE 使用相同样本和幻觉标签比较；
4. 按模型报告 AUROC、AUPRC、PRR 及 group-level bootstrap 置信区间；
5. 重点报告低不确定性幻觉子集上的增益，同时检查完整测试集性能是否退化；
6. 只有跨模型、跨数据集稳定复现的提升，才可视为有效改进。

## 5. 当前仓库边界

仓库当前只保留：

- 主实验生成、UQ、Judge 与指标计算代码；
- 三种 baseline 复现；
- 低不确定性幻觉子集提取代码与文档；
- 后续研究所需的统一数据和评估基础。

具体的不确定性量化改进方法将在下一阶段重新设计、实现和验证。
