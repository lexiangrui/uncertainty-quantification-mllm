# 实验一结果分析

本文档是主实验（三模型 × 三数据集 × 三种 UQ 方法，见[不确定性量化主实验](不确定性量化主实验.md)）结果分析的正式方案，基于对 `results/` 下实际数据的字段审计写成。分析产出以**数据表（CSV）和文字报告**为主，本阶段不构建绘图代码；每个分析项附"可绘图"说明，供后续报告制图使用。

---

## 0. 目标与总体约定

### 0.1 分析目标

1. **描述性统计**：数据有效性流转、标签结构、UQ 分数分布与方法间关系；
2. **检测性能对比**：三种 UQ 方法在错误检测（E = 1 − C）与幻觉检测（H）上的 AUROC、AUPRC、PRR 对比；
3. **LUH 画像与漏检归因**：低不确定性幻觉（LUH）的规模量化、三种方法各自漏检的信号原因、以及 LUH 样本的特征画像，直接服务下一阶段"改进 UQ 方法以识别 LUH"的研究。

### 0.2 输入与连接

| 输入 | 路径 | 用到的字段 |
|---|---|---|
| greedy 生成 | `results/generation/<model>/greedy/<dataset>.jsonl` | `sample`（sample_id、group_id、has_image、references、metadata）、`greedy.sections_valid`（XML 格式状态）、`greedy.answer/vision/reasoning`、`greedy.signals.token_count` |
| sampled 生成 | `results/generation/<model>/samples/<dataset>.jsonl` | `samples[i].answer`、`samples[i].sections_valid` |
| UQ 结果 | `results/uq/<model>/<dataset>.jsonl` | 各方法 `valid/score`；SE 的 `clusters`（簇成员与概率质量）；UMPIRE 的 `semantic_volume`、`incoherence_mean`、`alpha` |
| 正式人类对齐标签 | `results/judging/<model>/<dataset>.jsonl` | `judge.valid/correct/hallucination/rating/hallucination_types` |
| 已有指标 | `results/metrics/<model>/<dataset>.json` | 仅用于交叉核对，不作为分析输入 |
| LUH 子集 | `results/analysis/luh/per_model_subsets.json` | 每模型 200 正例 + 200 匹配负例 ID |

- **连接键**：`sample_id`；**评估单元**：模型 × 数据集单元格（9 个），与主实验文档 §7 一致，不做跨单元格的原始分数合并。
- **分数方向**：三种方法均为"分数越高，不确定性越高"。

### 0.3 排除规则（与 `results/metrics` 完全一致）

1. XML 解析失败（`sections_valid=false`）的样本不调用 Judge，记入 A1 流水账；
2. Judge 无效（`judge.valid=false`）的样本从所有标签分析中排除；
3. UQ 记录缺失的样本从"已评估"集合排除；
4. 某一方法分数无效（`valid=false`）只影响该方法的分析，记入方法级有效数。

### 0.4 统一统计约定

- **Bootstrap**：以 `group_id`（原始问题 ID）为聚类单位的重采样，B = 1000，种子 0，95% 置信区间；ViLP 同题三条 QIA 实例随问题一同重采样。与 `results/metrics` 的配置（`bootstrap_samples=1000, bootstrap_seed=0, cluster_field=group_id`）完全一致，保证 B1 可逐值核对。
- **指标实现**：直接复用 `src/evaluation/metrics.py` 的 `auroc / auprc / prr / cluster_bootstrap_indices / bootstrap_summary`，不另写第二套口径。
- **成对比较**：方法差、目标差（E vs H）等在同一组 bootstrap 重采样上配对计算差值分布，取百分位区间。
- 单一类别（无正类或无负类）时 AUROC/AUPRC/PRR 记 N/A，不插补。

## 2. 模块 A：描述性统计

脚本 `scripts/analysis/a_descriptive.py`，输出目录 `results/analysis/descriptive/`。

### A1 数据有效性流转

每个模型 × 数据集统计：greedy 记录数 → `sections_valid=true` 数 → Judge 有效数 → UQ 记录数 → 三方法各自有效数 → 三方法全有效数（即各方法指标计算的最终样本集）。

输出：`a1_validity_flow.csv`（列：model, dataset, n_greedy, n_sections_valid, n_judge_valid, n_uq_records, n_ppl_valid, n_se_valid, n_ump_valid, n_all3_valid）。

**可绘图**：桑基图/瀑布图展示每格的样本流转与损耗。

### A2 标签基础统计

- Accuracy、Hallucination Rate 及 95% CI（cluster bootstrap）；
- C ×H 四格表（正确且有幻觉、正确无幻觉、错误无幻觉、错误有幻觉）；
- Judge rating 0–6 分布；H=1 内 `hallucination_types` 构成（vision / reasoning / both）。

输出：`a2_label_stats.csv`、`a2_c_h_joint.csv`、`a2_rating_dist.csv`、`a2_hallu_types.csv`。Accuracy/幻觉率与 `results/metrics` 的 `labels` 字段交叉核对。

**可绘图**：9 格 Accuracy vs Hallucination Rate 散点（对角线参考）；rating 堆叠柱状图；C×H 四格构成百分比条。

### A3 UQ 分数分布与方法间关系

- 每格每方法：n、mean、std、median、Q1/Q3/IQR、偏度、P5/P95；
- 方法两两 Spearman/Kendall 秩相关（同格同样本，三方法全有效集合）。

输出：`a3_score_stats.csv`、`a3_rank_corr.csv`。

**可绘图**：对数坐标分数分布（按格分面的密度/箱线）；3×3 秩相关热图。

### A4 采样语义一致性（基于 SE 簇字段）

- 每题语义簇个数（K=10）的分布：均值、中位数、单簇占比；
- 多数簇概率质量的均值/中位数；
- **greedy 答案与多数簇答案的一致率**：将 greedy 答案与多数簇各成员答案做规范化文本匹配（小写、去首尾标点空白），按 全体/正确/错误/幻觉/无幻觉 分组报告一致率及 CI。该项为精确匹配近似，语义等价需 NLI，结论表述时注意。

输出：`a4_se_cluster_stats.csv`、`a4_greedy_majority.csv`。

**可绘图**：簇数分布直方图；一致率按分组的条形图（带 CI）。

## 3. 模块 B：检测性能对比

脚本 `scripts/analysis/b_detection.py`，输出目录 `results/analysis/detection/`。所有指标复用 `src/evaluation/metrics.py`，目标标签：错误检测 `Z=E=1-C`，幻觉检测 `Z=H`。

### B1 主表与交叉核对

每格每方法每目标：n、n_pos、正类率、AUROC、AUPRC、PRR 及各自 95% CI。

输出：`b1_metrics_main.csv`；`b1_crosscheck.csv` 将本表点估计与 `results/metrics/<model>/<dataset>.json` 逐值对比（同函数、同种子，应精确一致，容差 1e−9，不一致则报错列出）。

**可绘图**：3×3 AUROC 热图（分目标、分方法）；点估计+CI 的森林图。

### B2 方法对比、宏平均与目标差距

- **方法差**：格内两两方法（SE−PPL、UMPIRE−PPL、UMPIRE−SE）在三个指标上的配对差及 CI；
- **排名稳定性**：按 AUROC 统计每方法在 9 格中获胜次数与平均排名；
- **宏平均**：每模型跨三数据集的宏平均 AUROC 及 CI（各数据集用相同种子的重采样配对求宏平均分布，约定写入 report.md）；
- **E vs H 差距**：每格每方法 AUROC(H)−AUROC(E) 的配对差及 CI——量化"答案不确定性作为幻觉代理"的损失。

输出：`b2_method_diff.csv`、`b2_rank_stability.csv`、`b2_macro.csv`、`b2_target_gap.csv`。

**可绘图**：ΔAUROC 点图（方法对 × 模型）；E/H 目标差距发散条形图。

### B3 风险—覆盖数据

- 风险—覆盖曲线数据：按分数从高到低拒绝，1% 拒绝率网格上每格每方法每目标的保留精确率。

输出：`b3_risk_coverage.csv`。

**可绘图**：风险—覆盖曲线（含随机基线）。

### B4 C×H 子群分解

- 四组（C×H）的分数分布统计（原始值 + 格内百分位秩均值，后者消除方法量纲差异）；
- 错误类型分解 AUROC：以正确样本（C=1）为负类，分别以"错误且幻觉（E,H=1）""错误无幻觉（E,H=0）"为正类计算 AUROC 及 CI——回答"分数到底擅长抓哪类错误"。

输出：`b4_group_scores.csv`、`b4_group_pct.csv`、`b4_subgroup_auroc.csv`。

**可绘图**：四组分数（百分位秩）小提琴图；子群 AUROC 对比条形图。

## 4. 模块 C1：LUH 画像与漏检归因

脚本 `scripts/analysis/c1_luh_profile.py`，输出目录 `results/analysis/luh_profile/`。

**分组定义**（每模型，三数据集合并，与子集提取同池：Judge 有效 + 三方法分数全有效 + 有图）：

| 组 | 定义 | 规模 |
|---|---|---|
| `luh` | 子集正例（200 条，幻觉且三维平均百分位最低） | 200/模型 |
| `matched_neg` | 子集负例（三维百分位最近邻匹配的非幻觉样本） | 200/模型 |
| `detected_hallu` | 同池中 H=1 且不属于 `luh` 的样本（现有方法可覆盖的幻觉） | 每模型数百条 |

### C1.1 规模量化（每模型 × 每方法 × 两个 α 水平的占比）

对每个模型（三数据集合并的全体已评估样本）× 每种 UQ 方法，在 α ∈ {0.25, 0.50} 两个水平计算

$$
\mathrm{LUH\_share}(\alpha)=\Pr\!\left(s_{H=1}\le Q_{\alpha}(H_0)\right),
$$

即幻觉样本中不确定性分数小于等于非幻觉样本分布 α 分位（下四分位 / 中位数）的比例。该定义相对早期两个试用的口径（"低于 H=0 中位数"单独使用时锚在中带、"全体样本 bottom 25%"的分位位置受该格类别比例影响且跨格不可比）更准确地对应"低不确定性幻觉"；α=0.25 刻画与最自信的四分之一可靠回答同等自信的幻觉，α=0.50 给出中带参照。

零假设参照：分数与标签可交换（方法无信息）且分数连续时 LUH_share(α) 恰为 α，`excess = share − α` 衡量方法在该分位以下的失效程度——接近 0 表示盲区严重，越负表示低不确定性区的幻觉排除越有效。SE 在 0 处存在点质量（单语义簇）时 ≤ 口径的零假设略高于 α，解释时留意。阈值 Q_α(H₀) 与 95% CI（group_id 聚类 bootstrap，重采样内重估阈值）随表输出。

输出：`c1_luh_rate.csv`（model × method × α：n、阈值、luh_share、CI、null、excess）。

**可绘图**：每模型 × 方法的 LUH_share 分组条形图（α=0.25/0.50 两组，带 CI 与各自 α 零假设参考线）。

### C1.2 信号源归因（为什么测不出来）

- **PPL 漏检 → token 级自信**：三组的答案 token 数分布、答案格式构成（Yes/No、数字、≤3 token 短语、长文本）、PPL 与 token 数的秩相关（H=1 样本内）；
- **SE 漏检 → 采样收敛到同一错误含义**：`luh` vs `detected_hallu` 的簇数分布与多数簇质量对比（"一致但错误"的程度）；
- **UMPIRE 漏检 → 体积与不一致度双低**：三组的 `semantic_volume` 与 `incoherence_mean` 均值对比，判断哪一项分量在 LUH 上失效。

输出：`c1_answer_format.csv`、`c1_ppl_length_corr.csv`、`c1_se_clusters.csv`、`c1_umpire_components.csv`。

**可绘图**：token 数分布对比；簇数分布对比；UMPIRE 两分量散点（三组着色）。

### C1.3 特征画像（病例—对照）

三组在以下维度上的构成对比（含 95% CI）：

- 数据集来源；HallusionBench 内 VD/VS 类别；MM-Vet 能力类别；
- `hallucination_types`（vision / reasoning / both，限 H=1 组）；rating 严重度分布；C 标签构成（重点：**vision 幻觉且 C=1** 的 LUH——视觉观察有幻觉但答案碰对，纯答案空间方法原理上的盲区）；
- ViLP case 分组（case1 / case2/3，解释需对照数据源确认 prior/test 对应关系）。

输出：`c1_profile_dataset.csv`、`c1_profile_hb_category.csv`、`c1_profile_mmvet_cap.csv`、`c1_profile_types.csv`、`c1_profile_rating.csv`、`c1_profile_correct.csv`、`c1_profile_vilp_case.csv`。

**可绘图**：三组雷达图或百分比堆叠条（各维度）；"vision 幻觉且正确"占 LUH 比例的强调条形图。

## 6. 实施顺序与验收标准

顺序：A → B → C1（B 依赖的指标函数与 A 的有效性统计先行）。

验收标准：

1. `b1_crosscheck.csv` 与 `results/metrics` 全部一致（容差 1e−9），A2 的 Accuracy/幻觉率与 metrics `labels` 一致；
2. 所有比例/指标均带 `group_id` 聚类 bootstrap 的 95% CI，单一类别记 N/A；
3. C1 的 `luh`/`matched_neg` 组样本数恰为 200/200，与 `results/analysis/luh/` 的 ID 清单一致；
4. 每个结论可追溯到具体 CSV 文件与列。
