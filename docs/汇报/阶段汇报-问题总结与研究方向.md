# 阶段汇报：问题总结与下一步研究方向

## 1. 已完成工作

当前阶段已经完成：

1. Perplexity、Semantic Entropy、UMPIRE 三种不确定性量化方法的统一实现与主实验；
2. 三个多模态模型在 ViLP、HallusionBench、MM-Vet 上的生成、Judge、UQ 和指标评估；
3. 正确性与幻觉标签的独立判定；
4. 每个模型 200 条低不确定性幻觉正例与 200 条不确定性匹配非幻觉负例的子集构造。

## 2. 核心问题

现有不确定性量化方法在完整测试集上可以提供一定的错误或幻觉排序能力，但仍存在一类重要失效样本：模型产生了幻觉，却对回答表现出较高置信度和较低不确定性。

这类低不确定性幻觉可能同时表现为：

- greedy 答案概率较高；
- 多次采样回答语义一致；
- 回答内部表征集中。

因此，仅依赖现有输出概率或采样一致性信号，无法稳定识别这些样本。

## 3. 下一步方向

下一步研究问题确定为：

> 如何改进多模态大模型的不确定性量化方法，使其能够识别低不确定性幻觉子集？

研究将以已经构造的模型独立 400 条子集为主要困难集。该子集通过三维百分位最近邻匹配，使 PPL、Semantic Entropy 和 UMPIRE 在正负类之间的分数分布高度重叠，AUROC 接近随机水平。

现阶段不指定具体候选算法。此前探索的扰动、替换或组合方案不作为正式研究方法，相关代码已经删除。下一阶段将在明确评价构念和验证协议后重新设计方法。

## 4. 验证原则

后续方法必须遵循以下原则：

1. 先固定开发模型、开发数据和方法定义，再进行跨模型验证；
2. 主要目标是提高低不确定性幻觉子集上的幻觉检测能力；
3. 同时报告完整测试集结果，防止只对困难子集过拟合；
4. 与三种 baseline 使用完全相同的样本、标签和指标；
5. 报告 AUROC、AUPRC、PRR 及 group-level bootstrap 置信区间；
6. 方法方向和超参数不得根据最终测试模型的结果反复调整；
7. 只有跨模型、跨数据集稳定的提升才作为有效结论。

## 5. 下一阶段产出

下一阶段预期产出包括：

- 一套具有清晰不确定性或幻觉风险解释的改进方法；
- 可复现的训练或推理实现；
- 在低不确定性幻觉子集和完整测试集上的统一评估；
- 跨模型、跨数据集的消融与泛化验证。
