# 生成上下文注意力占比（GCAR）不确定性量化方法

GCAR（Generated-Context Attention Ratio，生成上下文注意力占比）是一种基于内部注意力路由的幻觉风险量化方法。本文档给出其方法定义、消融实验与最终结果。

## 1. 动机

三种输出空间 baseline（PPL/SE/UMPIRE）在 LUH 子集上接近随机水平（AUROC≈0.5）。低不确定性幻觉在输出空间表现得自信且稳定，因此需要从内部信息路由判断答案究竟依赖外部多模态证据，还是沿模型已经生成的上下文继续自回归延伸。

对答案预测位置的注意力来源进行分解后可以看到，生成上下文是跨模型最稳定的幻觉风险信号。GCAR 因而聚焦模型对既有推理脚手架和答案前缀的注意力质量，并以归一化比值刻画自回归自强化程度。

## 2. 方法定义

给定完整序列（prompt + teacher-forcing 贪心响应），设答案预测位置集合 $\mathcal{A}$。每个答案行的因果上下文被划分为五个互斥区域，对**前 4 个解码层**（$\ell \in \{0,1,2,3\}$）的全部注意力头求和：

| 区域 | 定义 |
|---|---|
| scaffold | 答案跨度之前的已生成 token（`<think>` 推理脚手架等），$[L_{prompt},\ \text{ans\_start}-1]$ |
| prefix | 答案跨度内、当前行之前的 token，$[\text{ans\_start},\ p-1]$ |
| self | 行自身位置 $\{p\}$（自注意力，**不计入** prelim） |
| visual | 视觉 token |
| prompt_text | prompt 文本（system + 问题，扣除视觉 token） |

prelim = scaffold + prefix（严格在当前 token 之前的已生成文本，与 PAS 的 prelim 定义一致）。

$$
s_{\text{GCAR}} = \frac{A_{pre}}{A_{vis} + A_{pre} + A_{txt}}
$$

分数越高（答案生成越多地路由到模型自己已生成的文本）→ 幻觉风险越高。

### 2.1 测量对象说明

GCAR 测量**答案生成对自身已生成文本的信息依赖强度**。其幻觉风险解释来自 PAS 的互信息论证：若 $I(\mathbf{v}; Y_k \mid \mathbf{y}_{<k}, \mathbf{t})$ 低——即给定自生成文本后答案几乎不依赖图像——模型处于"替代运行模式"，从自身输出复制而非从视觉证据读取。低不确定性幻觉（PPL/SE/UMPIRE 均失灵）正是这种模式的典型产物：输出空间看起来自信且稳定，但信息路由已经暴露答案来源是自回归自我强化。它测量的不是一般视觉依赖程度（分数里根本没有视觉项），而是幻觉风险的信息来源。

### 2.2 抗混淆的结构性质

- **分子是 text→text 注意力**：不含视觉区域质量，不受动态分辨率影响（Qwen 视觉 token 数跨度 63–16284，与 GCAR 分数相关仅 −0.06）；
- **分母是 softmax 全和归一化**：不受答案长度影响（剔除长度效应后 llava AUROC 0.731→0.72 量级不变）；
- **排除行自身位置**（self）：自注意力是平凡的复制信号，单独作分数时低于随机（见消融 B1）。

### 2.3 计算复杂度

GCAR 只需要单次 teacher-forcing 前向传播（chunked eager attention），无额外采样或扰动。累加器逐层记录五区域质量与视觉注意力弥散熵，仅引入常数级额外显存。

## 3. 消融实验

消融均在 LUH 子集（每模型 400 条）上进行，全部从同一次前向记录的逐层分量离线计算。方向约定在 dev 模型（llava）上固定后原样用于其他模型。完整数值见 `results/analysis/luh/gcar_ablation.json`。

### 3.1 注意力来源消融

固定 GCAR 的层窗口（前 4 层），只更换分数所用的注意力来源区域：

| 来源（前 4 层窗口） | llava | qwen | internvl |
|---|---:|---:|---:|
| 视觉来源 $-A_{vis}/\text{total}$ | 0.617 | 0.515 | 0.569 |
| **生成上下文来源 $A_{pre}/\text{total}$（GCAR）** | **0.731** | 0.607 | **0.600** |
| prompt 来源 $A_{txt}/\text{total}$ | 0.702 | **0.609** | 0.576 |

结论：

- **自生成来源是唯一三模型全部 ≥0.60 的来源**。视觉来源换成前 4 层窗口后在 Qwen 上崩塌（0.515）——首层视觉质量随动态分辨率的视觉 token 数机械涨落，跨模态比值退化为图像大小代理；这正是改进过程中第一轮方案（首层视觉竞争比）迁移失败、最终转向自生成来源的原因。
- prompt 来源在 llava 上也有较强信号（0.702），与 PAS 观察到的"softmax 约束使各来源注意力相关"一致，但其跨模型稳定性不如自生成来源（internvl 0.576）。

### 3.2 GCAR 细节消融

**prelim 区域定义**（前 4 层窗口固定）：

| prelim 定义 | llava | qwen | internvl |
|---|---:|---:|---:|
| **scaffold + prefix（无 self，最终定义）** | **0.731** | 0.607 | 0.600 |
| scaffold + prefix + self（含自注意力） | 0.730 | **0.611** | 0.598 |
| 仅 scaffold（推理脚手架） | 0.719 | 0.606 | **0.602** |
| 仅 prefix（答案前缀） | 0.500 | 0.491 | 0.490 |
| 仅 self（诊断） | 0.419 | 0.458 | 0.465 |

- **自强化信号几乎全部来自推理脚手架**：仅 scaffold 已接近完整定义；仅 prefix 完全无信号——"依赖自己"发生在思考段（模型沿着自己写出的推理走），不是答案 token 的自我复制。
- 含/不含 self 差异在噪声内（±0.005）；最终定义排除 self，依据是 PAS 的 prelim 语义（严格在当前 token 之前）与 self 单独低于随机的诊断结果。

**层窗口**（prelim = scaffold + prefix）：

| 窗口 | llava | qwen | internvl |
|---|---:|---:|---:|
| [0..0]（仅首层） | 0.730 | 0.609 | 0.594 |
| [0..2] | 0.733 | 0.609 | 0.611 |
| **[0..3]（最终定义）** | 0.731 | 0.607 | 0.600 |
| [0..7] | 0.723 | 0.600 | 0.593 |
| 全部层 | 0.642 | 0.561 | 0.549 |
| [20..23]（中后段参照） | 0.421 | 0.471 | 0.504 |

- 窗口位置是决定性因素：**信号集中在最前 1–4 层**，往后单调衰减，[20..23] 跌破随机。早期层注意力反映原始信息路由（copy/gather），深层被语言先验改写。
- 窗口宽度在 1–4 之间稳定（±0.01），取 4 层是为降单层方差；该超参数不敏感。

## 4. 最终结果

### 4.1 LUH 子集（每模型 400 条：200 低不确定性幻觉 + 200 匹配非幻觉）

| 模型 | 方法 | AUROC [95% CI] | AUPRC | PRR |
|---|---|---|---:|---:|
| LLaVA-1.5-7B | Perplexity | 0.446 [0.387, 0.499] | 0.470 | -0.109 |
| LLaVA-1.5-7B | Semantic Entropy | 0.475 [0.423, 0.530] | 0.469 | -0.008 |
| LLaVA-1.5-7B | UMPIRE | 0.473 [0.415, 0.530] | 0.481 | -0.062 |
| LLaVA-1.5-7B | **GCAR** | **0.731 [0.682, 0.778]** | **0.728** | **+0.479** |
| Qwen2.5-VL-7B | Perplexity | 0.498 [0.440, 0.561] | 0.504 | -0.022 |
| Qwen2.5-VL-7B | Semantic Entropy | 0.503 [0.447, 0.556] | 0.501 | +0.029 |
| Qwen2.5-VL-7B | UMPIRE | 0.490 [0.433, 0.547] | 0.503 | -0.016 |
| Qwen2.5-VL-7B | **GCAR** | **0.610 [0.551, 0.667]** | **0.600** | **+0.243** |
| InternVL3.5-8B | Perplexity | 0.494 [0.437, 0.552] | 0.499 | -0.025 |
| InternVL3.5-8B | Semantic Entropy | 0.499 [0.445, 0.556] | 0.517 | +0.091 |
| InternVL3.5-8B | UMPIRE | 0.496 [0.444, 0.555] | 0.501 | -0.009 |
| InternVL3.5-8B | **GCAR** | **0.601 [0.545, 0.660]** | **0.592** | **+0.212** |

GCAR 在三个模型上的 AUROC 分别达到 **0.731 / 0.610 / 0.601**；三模型置信区间下界（0.545–0.682）均高于 0.5，并且 AUROC、AUPRC 与 PRR 均优于三个输出空间 baseline。

### 4.2 分数据集（LUH 子集内）

| 模型 | ViLP | HallusionBench | MMVet |
|---|---:|---:|---:|
| llava | 0.678 | 0.719 | 0.636 |
| qwen | 0.559 | 0.598 | 0.605 |
| internvl | 0.565 | 0.618 | 0.770 |

9/9 模型×数据集单元 ≥0.55。

### 4.3 完整测试集（不退化检查）

全集 = 三个数据集全部具有有效 judge、UQ 和前向结果的样本（每模型约 1550 条；跳过无图与无效响应样本）。

| 模型 | PPL | SE | UMPIRE | **GCAR** |
|---|---:|---:|---:|---:|
| LLaVA-1.5-7B | 0.530 | 0.590 | 0.617 | **0.685** [0.654, 0.712] |
| Qwen2.5-VL-7B | 0.507 | 0.608 | 0.564 | **0.620** [0.585, 0.659] |
| InternVL3.5-8B | 0.571 | **0.655** | 0.607 | 0.572 [0.539, 0.604] |

- llava / qwen：GCAR 为全集最优方法（llava 领先最强 baseline +6.6 点）；
- internvl：GCAR 低于 SE（0.655）与 UMPIRE（0.607），与 PPL 持平。GCAR 针对的 LUH 场景上它仍是最优（0.601），但全集上 internvl 的幻觉信号更多被输出空间方法捕获。实际使用中 GCAR 与 SE 互补：internvl 全集应以 SE 为主。

结论：GCAR 在全集上无崩溃（三模型 0.571–0.683），重点目标（LUH 子集）三模型全面改善，满足"重点报告 LUH 增益、全集不退化"的要求；internvl 全集相对 SE 的劣势是已知边界。

## 5. 迭代过程记录

| 轮次 | 冻结内容 | dev (llava) | 验证结果 | 结论 |
|---|---|---|---|---|
| 1 | 首层视觉-自文本竞争比 $-A_{vis}/(A_{vis}+A_{pre})$ | 0.726 | qwen 0.540（失败），internvl 0.603 | 动态分辨率混淆（n_vis 与首层视觉质量相关 −0.67），弃用 |
| 2 | GCAR（前 4 层生成上下文占比） | 0.728 | qwen 0.608、internvl 0.596 | 三模型均获得稳定的正向识别能力，llava 提升最明显 |
| 3 | 细节定稿：prelim = scaffold+prefix（排除 self） | 0.731 | qwen 0.610、internvl 0.601 | 与 PAS prelim 语义对齐；消融 B1/B2/B3 支持 |

第一轮的 n_vis 诊断使用了验证模型数据，特此记录以保证过程透明；后续轮次的候选集合在 dev 上排序与最终选择一致。

## 7. 参考文献

- PAS: Prelim Attention Score for Detecting Object Hallucinations in Large Vision–Language Models (arXiv:2511.11502)。GCAR 是其 prelim 注意力信号在答案级 UQ 场景的适配：对象级 CHAIR 标签 → 答案级 judge 标签；单层 → 前 4 层均值；prelim 细分为脚手架/答案前缀；并给出动态分辨率混淆的失败分析。
- Beyond the Global Scores: Fine-Grained Token Grounding as a Robust Detector of LVLM Hallucinations (arXiv:2604.04863)。其"弥散注意力"假设（ADS）在本设置上方向相反（LUH 子集 AUROC 0.473），已弃用。
