# 直接注意力比（ECA / U_direct）不确定性量化方法

ECA 的最终定义为早期直接注意力比：答案 token 的注意力流向模型自生成正文的比例越高，说明答案越依赖模型内部生成的上下文而非外部输入，幻觉风险越高。

## 方法定义

给定 prompt 与模型实际生成的响应 token 序列，将注意力目标划分为六个区域：

| 区域 | 定义 |
|---|---|
| I | 图像 token |
| Q | system prompt 与问题文本 |
| V | `<vision>` 正文 |
| R | `<reasoning>` 正文 |
| A | `<answer>` 正文 |
| tags | XML 标签、片段间空白及跨越 XML 边界的 token |

在解码层 0 和 1 上，对全部注意力头求和。记 $\alpha(A\to T)$ 为答案预测行流向区域 $T$ 的平均注意力质量：

$$
U_{\mathrm{direct}} =
\frac{\alpha(A\to V)+\alpha(A\to R)}
{\alpha(A\to I)+\alpha(A\to Q)+\alpha(A\to V)+\alpha(A\to R)+\alpha(A\to A)+\epsilon}.
$$

`tags` 桶仅用于审计和标签消融，不进入最终指标的分子或分母。

## Token 对齐

ECA 直接读取生成阶段保存的 greedy token IDs，并用完整响应的一次 tokenizer offset mapping 标记区域。只有完全位于正文字符区间内的 token 才进入 V、R 或 A；XML token、空白 token 和跨边界 token 均归入 `tags`。

运行时必须同时满足：

1. 保存的 token IDs 解码后与 `raw_response` 一致；
2. 完整响应编码得到的 IDs 与保存的生成 IDs 一致；
3. V、R、A 均至少包含一个不跨 XML 边界的 token。

任一条件不满足即终止并报告对齐错误，不分段重编码，也不静默回退。由此保证 teacher forcing 使用模型实际生成的文本 token 序列。
