# 直接注意力比（ECA / U_direct）不确定性量化方法

ECA 的核心思想为早期直接注意力比（Direct Attention Ratio）：量化模型在给出最终答案时，对自身生成的思考与描述（$V+R$）相较于真实外部输入（$I+Q$）的相对依赖程度。比值越高，表明答案越依赖模型自生成的上下文而非客观输入，内生不确定性与幻觉风险越高。

## 一、方法定义

给定 Prompt 与模型实际生成的响应 Token 序列，采用连续 Token 切片将注意力目标划分为 5 个区域（保留 XML 标签，零分词器依赖，零短答案丢失）：

| 区域 | 定义 | 语义属性 |
|---|---|---|
| **I** | 图像 Visual Tokens | 客观真实输入（Grounded Input） |
| **Q** | System Prompt 与问题文本 Tokens | 客观真实输入（Grounded Input） |
| **V** | `<vision>...</vision>` 连续切片 | 模型自生成上下文（Generated Rationale） |
| **R** | `<reasoning>...</reasoning>` 连续切片 | 模型自生成上下文（Generated Rationale） |
| **A** | `<answer>...</answer>` 连续切片 | 最终答案决策（Decision Target） |

在解码器浅层（第 0 和 1 层）上，对全部注意力头求和。记 $\alpha(A\to T)$ 为答案预测行流向目标区域 $T$ 的平均注意力质量。

### 标准指标 $U_{\mathrm{direct}}$ 定义
$$
U_{\mathrm{direct}} =
\frac{\alpha(A\to V) + \alpha(A\to R)}{\alpha(A\to I) + \alpha(A\to Q) + \alpha(A\to V) + \alpha(A\to R) + \epsilon}
$$

- **物理意义与理论优势**：
  1. **排除局部句法干扰**：分母主动排除了 Answer 内部的局部自回归自注意力（$A\to A$），确保指标具有**回答长度不变性（Length Invariance）**，不受答案长短或格式词多寡的干扰。
  2. **相对锚定比率（Grounding Odds Ratio）**：
     $$U_{\mathrm{direct}} = \frac{\text{自生成先验 (Generated Rationale)}}{\text{外部事实输入 (Ground-truth Inputs)} + \text{自生成先验 (Generated Rationale)}}$$
     直接度量模型决策时外部事实锚定与自生先验的相对权重比。

## 二、Token 对齐协议

采用原生 Token 序列增量前缀切片：
1. 直接读取生成阶段保存的 greedy token IDs，剥离尾部 EOS / PAD；
2. 基于增量解码定位 `<reasoning` 与 `<answer` 的起始 token 索引，切分为三个连续区间；
3. 零重编码，100% 保持 Teacher Forcing 序列的原生性，短答案样本有效率 100%。
