# 直接注意力比（ECA / U_direct）不确定性量化方法

ECA 的最终定义为早期直接注意力比：答案 token 的注意力流向模型自生成前文（视觉描述与推理过程）的比例越高，说明答案越依赖模型内部生成的上下文而非外部输入，幻觉风险越高。

## 方法定义

给定 prompt 与模型实际生成的响应 token 序列，采用连续 Token 切片划分注意力目标区域（保留 XML 标签，零分词器依赖，零短答案丢失）：

| 区域 | 定义 |
|---|---|
| I | 图像 Visual Tokens |
| Q | System prompt 与问题文本 Tokens |
| V | `<vision>...</vision>` 连续切片 |
| R | `<reasoning>...</reasoning>` 连续切片 |
| A | `<answer>...</answer>` 连续切片 |

在解码层 0 和 1 上，对全部注意力头求和。记 $\alpha(A\to T)$ 为答案预测行流向目标区域 $T$ 的平均注意力质量：

### 1. 标准指标 $U_{\mathrm{direct}}$（包含自注意力 $A\to A$）
$$
U_{\mathrm{direct}} =
\frac{\alpha(A\to V)+\alpha(A\to R)}
{\alpha(A\to I)+\alpha(A\to Q)+\alpha(A\to V)+\alpha(A\to R)+\alpha(A\to A)+\epsilon}
$$
在因果注意力下，分母所有目标区域注意力之和恒等于 1.0。

### 2. 消融指标 $U_{\mathrm{direct\_no\_aa}}$（分母剔除自注意力 $A\to A$）
$$
U_{\mathrm{direct\_no\_aa}} =
\frac{\alpha(A\to V)+\alpha(A\to R)}
{\alpha(A\to I)+\alpha(A\to Q)+\alpha(A\to V)+\alpha(A\to R)+\epsilon}
$$
- **物理意义**：衡量在所有流向前文外部上下文（$I+Q+V+R$）的注意力中，模型对自身生成内容（$V+R$）相较于真实外部输入（$I+Q$）的相对依赖比例，彻底消除 Answer 内部 token 长度对注意力的稀释。

## Token 对齐协议

采用原生 Token 序列增量前缀切片：
1. 直接读取生成阶段保存的 greedy token IDs，剥离尾部 EOS / PAD；
2. 基于增量解码定位 `<reasoning` 与 `<answer` 的起始 token 索引，切分为三个连续区间；
3. 零重编码，100% 保持 Teacher Forcing 序列的原生性，短答案样本有效率 100%。
