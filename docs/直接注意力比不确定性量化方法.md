# 直接注意力比（ECA / U_direct）不确定性量化方法

ECA 的最终定义为**早期直接注意力比**：答案 token 的注意力中流向模型自生成内容（vision/reasoning 正文）与外部输入（image/question）的直接比值。分数越高（答案越多地建立在自生成文本上）→ 幻觉风险越高。

## 1. 方法定义

给定完整序列（prompt + teacher-forcing 贪心响应），设答案预测位置集合 $\mathcal{A}$（行 $t-1$ 预测 token $t$，PAS 约定）。五个语义区域 + 一个标签桶：

| 区域 | 定义 |
|---|---|
| I | 图像 token |
| Q | prompt 文本（system + 问题，扣除图像 token） |
| V | `<vision>` 正文（不含标签） |
| R | `<reasoning>` 正文（不含标签） |
| A | `<answer>` 正文（不含标签） |
| tags | XML 标签 / 片段间空白（仅记录，**不进任何特征**） |

对**解码层 0 和 1**（冻结于 2026-08-18）、全部注意力头求和，$\alpha(A{\to}T)$ 为答案行对区域 $T$ 的头均注意力质量：

$$
U_{\text{direct}} = \frac{\alpha(A{\to}V) + \alpha(A{\to}R)}{\alpha(A{\to}I) + \alpha(A{\to}Q) + \alpha(A{\to}V) + \alpha(A{\to}R) + \alpha(A{\to}A) + \epsilon}
$$

### 1.1 XML 标签排除（分段重编码）

响应按"标签片段 / 正文片段"切开分别 tokenize 再拼接（`backend._piecewise_encode`）：BPE 无法把标签残片（如 `.</`）合并进正文 token，非空正文必有 token（零样本丢弃），各段跨度精确；相比整串编码每样本多 2–4 个边界 token。标签与正文物理隔离，任何特征都不含标签质量（消融见 §4.2）。

### 1.2 测量对象

与 GCAR 同族但更直接：GCAR 测"prelim 占全注意力的比例"（含 prompt 文本与标签在分母、层窗 0–3），U_direct 测"答案的直接注意力在**自生成正文 vs 外部输入**之间的分配"（分母不含标签、层窗 0–1）。两者共享同一条 teacher-forcing 流水线与自回归自我强化的动机：低不确定性幻觉在输出空间自信稳定（PPL/SE/UMPIRE 失效），只有内部信息路由暴露证据来源。

## 3. 迭代历史（方法收敛记录）

| 阶段 | 内容 | 结论 |
|---|---|---|
| 证据链（已删除） | 递归锚定 G_V/G_R → G_A → U_ECA = 1−G_A，检验答案信息能否沿 I→V→R→A 追溯回视觉证据 | **不成立**：U_ECA（最优带 0.584/0.592/0.574）从未超过 U_direct；锚定中间量无跨模型信号且最优层散布在 rel 0.43–0.89。删除，仅保留否定性记录于 git 历史 |
| 收敛到 U_direct | 自生成正文 vs 外部输入的直接比值，层 0–1，无标签 | 三模型全面超过 GCAR |

## 4. 消融实验

### 4.1 层选择（`results/analysis/eca/layer_sweep_v3.json`）

逐层 AUROC 最优层：llava **L0** = 0.729、qwen **L1** = 0.618、internvl **L1** = 0.624——三模型一致集中在前 1–2 层（rel 0.00–0.04），与 PAS 层消融及 GCAR 逐层曲线一致（早期层做信息路由，深层被语言先验改写）。窗口宽度 1–4 不敏感；最终取 **层 0–1 均值**（0.725/0.617/0.610）。

### 4.2 XML 标签保留/去除（`scripts/analysis/ablate_xml_tags.py` → `xml_tag_ablation.json`）

| 变体（层 0–1） | llava | qwen | internvl |
|---|---:|---:|---:|
| **去除标签（最终定义）** | **0.725** | **0.617** | **0.610** |
| 保留标签 | 0.717 | 0.613 | 0.605 |

保留标签（把 tags 桶并入自生成项与分母）在 U_direct 上**三模型一致更差**（−0.4 至 −0.9 点）——与 GCAR 侧（保留略高 1.3–2.1 点）方向相反：U_direct 的分母是语义注意力全和，标签进入后同时稀释了 I/Q 项的相对占比。**最终定义不保留标签**，与分段重编码策略一致。
