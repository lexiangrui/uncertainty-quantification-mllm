# 视觉基础分数 (Visual Grounding Score, VGS) 不确定性量化方法

> **改进方法**：VGS 的后继方法 EPAR（首层自生成注意力占比）见 [首层自生成注意力占比不确定性量化方法.md](首层自生成注意力占比不确定性量化方法.md)。

## 1. 动机

三种 baseline 方法（PPL、SE、UMPIRE）均从**输出空间**衡量不确定性。在低不确定性幻觉（LUH）子集上，它们的 AUROC 接近 0.5（随机水平），因为这些方法无法检测模型"自信地依赖语言先验给出错误答案"的情况。

**核心观察**：幻觉标签 H 评价的是视觉观察与推理部分。如果一个答案的生成过程几乎没有关注视觉 token，那么这个答案很可能来自语言先验而非视觉证据——这正是幻觉的典型来源。

## 2. 方法定义

### 2.1 直觉

在 Transformer 中，每个生成 token 的注意力分布告诉我们模型"在看哪里"。对于答案 token，如果注意力主要指向**视觉 token**（图像编码向量），说明答案基于视觉证据；如果注意力主要指向**文本 token**（问题、上下文），说明答案基于语言先验。

### 2.2 形式化

给定完整序列（prompt + 生成响应），设：

- $\mathcal{V}$：视觉 token 位置集合（$|\mathcal{V}| = N_v$，如 LLaVA 的 576 个）
- $\mathcal{A}$：答案预测位置集合（预测答案 token 的位置，$|\mathcal{A}| = M_a$）
- $A^{(\ell,h)}(i, j)$：第 $\ell$ 层第 $h$ 个注意力头中，位置 $i$ 对位置 $j$ 的注意力权重

**视觉基础比例**：

$$
r = \frac{\sum_{\ell \in \mathcal{L}} \sum_{h} \sum_{i \in \mathcal{A}} \sum_{j \in \mathcal{V}} A^{(\ell,h)}(i,j)}
{\sum_{\ell \in \mathcal{L}} \sum_{h} \sum_{i \in \mathcal{A}} \sum_{j} A^{(\ell,h)}(i,j)}
$$

其中 $\mathcal{L}$ 为选定的层范围（中间至后段层，如 LLaVA-7B 的第 11–32 层）。

### 2.3 分数

$$
s_{\text{VGS}} = -r
$$

- $r$ 越低（答案对视觉 token 的注意力占比越小）→ 答案越依赖语言上下文 → **不确定性越高**
- $r$ 越高 → 答案基于视觉证据 → 不确定性越低

分数越高表示不确定性越高，与 PPL、SE、UMPIRE 方向一致。

### 2.4 测量对象说明

VGS 测量的是**答案生成过程对视觉输入的注意力基础程度**，而非一般视觉依赖度。它直接回答："模型在生成答案时，有多少注意力指向了图像编码？"

较低的视觉注意力比例 $r$（即较高、更接近 0 的 VGS 不确定性分数）意味着模型在生成答案时较少直接关注视觉 token，是视觉幻觉风险的候选信号。

## 3. 实现

### 3.1 前向传播

需要单次 teacher-forcing 前向传播，设置 `output_attentions=True`。

**关键约束**：FlashAttention2 和 SDPA 不返回注意力权重，必须使用 `attn_implementation="eager"`。

### 3.2 注意力聚合

1. 识别视觉 token 位置（`input_ids == image_token_id`）
2. 识别答案预测位置（答案 token 前一位的位置）
3. 对选定层范围的所有注意力头，累计从答案预测位置到视觉位置的注意力总量
4. 除以从答案预测位置到所有位置的总注意力

### 3.3 计算复杂度

单次前向传播，无需多次采样或扰动。Eager attention 比 FlashAttention2 慢约 2–3 倍，但每个样本仍只需约 1 秒。

## 4. 实验结果

### 4.1 LUH 子集上的最终结果（每模型 400/400 完整样本）

| 模型 | 方法 | AUROC [95% CI] | AUPRC | PRR | ECE |
|---|---|---|---:|---:|---:|
| LLaVA-1.5-7B | Perplexity | 0.446 [0.387, 0.499] | 0.470 | -0.109 | 0.482 |
| LLaVA-1.5-7B | Semantic Entropy | 0.475 [0.423, 0.530] | 0.469 | -0.008 | 0.291 |
| LLaVA-1.5-7B | UMPIRE | 0.473 [0.415, 0.530] | 0.481 | -0.062 | 0.236 |
| LLaVA-1.5-7B | **VGS** | **0.592 [0.533, 0.647]** | **0.598** | **+0.202** | **0.176** |
| Qwen2.5-VL-7B | Perplexity | 0.498 [0.440, 0.561] | 0.504 | -0.022 | 0.487 |
| Qwen2.5-VL-7B | Semantic Entropy | 0.502 [0.447, 0.556] | 0.501 | +0.029 | 0.378 |
| Qwen2.5-VL-7B | UMPIRE | 0.490 [0.433, 0.547] | 0.503 | -0.016 | 0.345 |
| Qwen2.5-VL-7B | **VGS** | **0.602 [0.543, 0.657]** | **0.601** | **+0.202** | **0.299** |
| InternVL3.5-8B | Perplexity | 0.494 [0.437, 0.552] | 0.499 | -0.025 | 0.478 |
| InternVL3.5-8B | Semantic Entropy | 0.499 [0.445, 0.556] | 0.517 | +0.091 | 0.386 |
| InternVL3.5-8B | UMPIRE | 0.496 [0.444, 0.555] | 0.500 | -0.009 | 0.473 |
| InternVL3.5-8B | **VGS** | **0.569 [0.508, 0.627]** | **0.563** | **+0.189** | **0.115** |

VGS 在三个模型的全部四个指标（AUROC、AUPRC、PRR、ECE）上均优于三个 baseline：

- **AUROC**：VGS 0.569–0.602，置信区间下界为 0.508–0.543，均高于随机水平 0.5；三个 baseline 的区间均跨越 0.5。
- **AUPRC**：VGS 0.563–0.601，比 baseline（0.469–0.517）高约 4.6–10.0 个百分点。
- **PRR**：VGS 稳定在 +0.189–0.202；baseline 在 -0.109 至 +0.091 之间波动。
- **ECE**：按当前测试集 min-max 归一化口径，VGS 在三个模型上均为最低（0.115–0.299）；该数值仅作分数分布诊断，不等同于独立校准集上的概率校准结果。

### 4.2 视觉注意力比例

幻觉样本的视觉注意力比例始终低于非幻觉样本，跨模型方向一致。
