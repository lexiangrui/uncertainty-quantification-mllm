# 证据链注意力不确定性方法（ECA）可行性实验

**结论先行：ECA 的核心创新（递归证据链锚定）在本任务上不成立。** U_ECA 在三个模型上全面弱于简单比值 U_direct 与现有方法 GCAR；证据链的两个锚定项（G_V、G_R）没有跨模型稳定信号，且答案的直接图像注意力方向与假设相反。GCAR（首 4 层自生成注意力占比）仍是最优方法。

## 1. 假设

ECA（Evidence-Chain Attention）把 prediction uncertainty 改造为 evidence-grounding uncertainty：答案依赖的信息能否沿注意力路径 I → V → R → A 追溯回原始视觉证据。五个区域：I（图像 token）、Q（问题文本）、V（`<vision>` 自生成视觉描述）、R（`<reasoning>` 自生成推理）、A（`<answer>`）。分数链：

- G_V = α(V→I) / (α(V→I)+α(V→Q)+ε)——视觉描述是否来自图像
- G_R = (α(R→I)+α(R→V)·G_V) / (α(R→I)+α(R→Q)+α(R→V)+ε)——推理是否沿视觉证据
- G_A = (α(A→I)+α(A→V)·G_V+α(A→R)·G_R) / (α(A→I)+α(A→Q)+α(A→V)+α(A→R)+ε)
- U_ECA = 1 − G_A；基线 U_direct = (α(A→V)+α(A→R)) / (α(A→V)+α(A→R)+α(A→I)+α(A→Q)+ε)

## 2. 实现

- 每样本一次 teacher-forcing 前向（chunked eager attention，与 GCAR 流水线同源），逐层记录 3 个 source 组（V/R/A 的预测行，t−1 约定）× 5 个 destination 桶（I/Q/V/R/A）的注意力质量，全部特征离线计算。
- **XML 标签不入区域**：字符区间取正则内容段；overlap 命中的首尾 token 若含 `<`/`>` 字符则剔除（BPE 会把内容句号与 `</` 合并成 `.</` 这样的残片 token），纯标签 token 均为 unbucketed。
- 代码：`src/improvement/eca.py`、`scripts/improvement/run_eca.py`（输出 `results/eca_components/`）。

## 3. 实验协议

- 层扫描直接在每模型 400 条 LUH 子集上进行（2026-08-18 决定，弃用独立开发集以最大化该集性能）。**注意：层带在该集合上选取，报告数字对层带选择是 in-sample 的。**
- 扫描：8 特征 × 全部层（llava 32 / qwen 28 / internvl 36）× 三模型，`scripts/analysis/sweep_eca_layers.py` → `results/analysis/eca/layer_sweep.json`。
- 作业经 sbatch 提交（`slurm/improvement/run_eca.sbatch`，debug01 分区）。

## 4. 结果（LUH 400，early 带 [0, 1/3)，AUROC）

| 方法 | llava | qwen | internvl |
|---|---:|---:|---:|
| aAI（answer→image 注意力） | 0.425（方向反） | 0.434（方向反） | 0.401（方向反） |
| U_direct（自生成 vs 输入比） | 0.705 | 0.571 | 0.573 |
| G_V（vision 锚定） | 0.514 | 0.464 | 0.421 |
| G_R（reasoning 锚定） | 0.584 | 0.481 | 0.441 |
| U_ECA（完整证据链） | 0.441 | 0.547 | 0.566 |
| GCAR（对照，前 4 层） | **0.731** | **0.607** | **0.600** |

逐层扫描补充：U_ECA 无跨模型一致的层段（llava 信号在 L1 但方向相反 1−AUROC=0.70，qwen L5=0.60，internvl L8=0.60，各模型最优层与方向均不一致）；U_direct 的早期带是唯一方向三模型一致的配置。

## 5. 失败原因分析

1. **锚定项是噪声**：G_V 在三模型上方向都不一致（llava 0.51 / qwen 0.46 / internvl 0.42）——"vision 描述来自图像还是问题"不区分 LUH 幻觉。G_V 无信号，把它乘进 G_R、G_A 的 V 路径只是注入噪声。
2. **直接图像注意力方向与假设相反**：幻觉样本的 answer→image 注意力**更高**（aAI 三模型 0.40–0.43）。低不确定性幻觉不是"不看图"，输出空间方法失效的原因在别处（自回归自我强化，GCAR 正是测这个）。U_ECA 分子里的 α(A→I) 项因此在"higher=uncertain"约定下是反向注入。
3. **链式结构放大而非消除噪声**：U_ECA = U_direct 信号（aAV+aAR 项）被两个无信号锚定项加权稀释。数据上 U_ECA < U_direct 恒成立。
4. U_direct 本身是 GCAR 的近亲（分子同为自生成质量，分母少了 prompt-text 项），而 GCAR 保留 prompt-text 在分母中反而更好——进一步说明有用信号是"自生成占比"本身，不是模态间的证据溯源。

## 6. 结论与保留物

- **不建议继续 ECA 方向**：递归证据锚定在 LUH 上无跨模型信号，与"视觉依赖"类信号一样受语言先验改写与动态分辨率影响。
- 分支保留：ECA 组件数据（`results/eca_components/`，含全部层 × 9 个 α 质量）与扫描/评估脚本，作为证据链假设的否定性实验记录；五区域分解与标签剔除实现可复用。
- 现行最优方法仍是 GCAR（LUH 0.731/0.607/0.600）。
