# 证据链注意力不确定性方法（ECA）

## 1. 方法假设

ECA（Evidence-Chain Attention）将不确定性解释为证据锚定程度：答案依赖的信息能否沿 I → V → R → A 的注意力路径追溯到原始视觉证据。I、Q、V、R、A 分别表示图像 token、prompt 文本、`<vision>` 内容、`<reasoning>` 内容和 `<answer>` 内容。

在每个解码层上，定义：

- G_V = α(V→I) / [α(V→I)+α(V→Q)+α(V→V)+ε]
- G_R = [α(R→I)+α(R→V)G_V] / [α(R→I)+α(R→Q)+α(R→V)+α(R→R)+ε]
- G_A = [α(A→I)+α(A→V)G_V+α(A→R)G_R] / [α(A→I)+α(A→Q)+α(A→V)+α(A→R)+α(A→A)+ε]
- U_ECA = 1 − G_A
- U_direct = [α(A→V)+α(A→R)] / [α(A→I)+α(A→Q)+α(A→V)+α(A→R)+α(A→A)+ε]

同时保留 `U_image`、`U_direct`、`U_V` 和 `U_R` 作为可解释的中间特征，所有输出统一为数值越大、不确定性越高。

## 2. 实现约定

- 每个样本只做一次 teacher-forcing 前向，逐层累积 V/R/A 预测行到 I/Q/V/R/A 五个区域的注意力质量。
- 预测行与 source 组标签一一对齐，不依赖 XML 区间在 token 序列中连续。
- **XML 标签排除（分段重编码）**：响应按"标签片段 / 正文片段"切开后分别 tokenize 再拼接（`backend._piecewise_encode`）。BPE 无法把标签残片（如 `.</`）合并进正文 token，每个非空正文段必有 token（零样本丢弃），各段 token 跨度精确；相比整串编码每样本多 2–4 个边界 token。
- 五个区域之外的 XML/control token 保持 unbucketed，不会进入任何特征分子或分母。
- 输出写入 `results/eca_components_v3/`（`regions-v4`）；v2/v3 旧组件数据与当前定义不兼容，不再用于评估。

## 3. 评估协议

层扫描依照当前实验协议，直接在每个模型的 400 条 LUH 子集上进行。因此，层窗口选择与最终评估使用同一数据集，报告时必须明确标注为 in-sample 结果。评估统一调用项目的 AUROC、AUPRC 和 PRR 实现。

## 5. 结论

**证据链假设在干净口径下仍然不成立**：U_ECA 不超过任何单一特征，更低于 U_direct 与 GCAR。修复 XML 标签污染后的两点新观察：

1. **U_V 方向变得跨模型一致**（mid 带 0.65/0.57/0.64；旧数据 0.38–0.51 乱向）——标签 token 的注意力确实在污染 vision 锚定项，但即便去污染后它仍弱于简单比值；
2. ECA 家族全部特征方向一致且高于随机，说明五区域分解本身有效；失效的是**递归锚定的组合方式**——G_V/G_R 作为中间量信息量不足，把它们乘进 G_A 只会稀释 U_direct 已有的信号。

GCAR（0.710/0.602/0.578）保持最优。ECA 分支保留为否定性实验记录：组件数据（`results/eca_components_v3/`，全层 × 15 个 α 质量）、扫描/评估脚本与分段重编码实现可复用。
