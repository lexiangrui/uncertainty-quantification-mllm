# 语义锚干预（Semantic Anchor Intervention, SAI）不确定性量化方法

> 状态：开发模型 LLaVA-1.5-7B 上定型并冻结；Qwen2.5-VL-7B 与 InternVL3.5-8B 跨模型验证见 §5。
> 分支：`improvement/sai`（自 `main` 新建，与 CRS / LSB / VGS 并列）

## 1. 动机与研究问题

三种 baseline（PPL、SE、UMPIRE）从**输出空间**测量不确定性，在低不确定性幻觉（LUH）子集上全部退化为随机水平：这些样本的答案 token 概率高、采样语义稳定、内部表征集中——输出空间里它们与"自信正确"不可区分。

本方法回到因果链的起点：**模型对自己声称看到的 object，其视觉语义证据是否真的支撑这个声称**。核心研究问题（即本分支要回答的 boxed question）：

> 模型对其生成 object 所对应视觉语义证据的**响应**，能否揭示传统 predictive uncertainty 无法识别的低不确定性幻觉？

为此设计的测量不是读出静态相关性，而是一个**反事实剂量-响应实验**：把（lens 定位到的）object 视觉证据沿其语义锚方向推近 / 推远，观测模型内部与输出对这条声称的信念如何移动。低不确定性幻觉的预期签名不是笼统的"变化大/小"，而是两个分量：

1. **支持亏缺（support deficit）**：声称首次出现时 teacher-forced logit 偏低（信念没有被模型自身前缀撑起）；
2. **异常的语义可塑性（anchor propagation）**：向语义锚推近视觉证据时，object 在末端 lens 读出的抬升反而更大——未被真实证据"钉住"的语义可以被注入任意放大，而真实读到的 object 读出已接近饱和、传播响应小。

## 2. 方法定义

### 2.1 管线（对每条 greedy 主回答，全部量在同一次提取中落盘）

1. **Object 提取（独立文本模型）**：Qwen3-4B-Instruct-2507 从 `<vision>/<reasoning>/<answer>` 三段文本中抽取"回答声称在图中可见的具体视觉 object"（含动物、人、器物、chart 元素、可见字母/数字），不使用任何数据集 GT object 类别；用整词正则在原文中定位提及的字符跨度并归入所在段。每样本取前 3 个 object，过滤纯颜色/方位词。
2. **锚 token 解析**：每个 object 映射到词表中首个非空白子词 token（LLaMA 系分词器会把前导空格拆成独立 token 29871，必须跳过，否则所有 object 共享同一个"空格锚"）。
3. **Vision Logit Lens 定位**：teacher-forced 基线前向取出各层隐状态；第 $L$ 层入口的视觉 token 状态经（final norm → lm_head）投影到词表空间，object 锚 token 的 log-prob 对 576 个视觉 token 构成"证据读出"分布；取 top-$k$（$k{=}16$）视觉位置作为该 object 的**证据位置**。
4. **语义锚**：两种构造，均为单位方向、在 $L$ 层入口的 pre-norm 残差空间中作用：
   - `unembed`（词表锚）：$u=\mathrm{normalize}\big((W_t-\bar W)\odot g\big)$，$W_t$ 为锚 token 的 unembedding 行，$\bar W$ 为词表均值，$g$ 为 final RMSNorm 增益（把词表方向换算到 pre-norm 几何）；
   - `mention_state`（上下文锚）：模型自己在该 object **首次提及处**的第 $L$ 层隐状态 $a$；各证据位置的方向为 $(a-h_i)$ 归一化（"把视觉证据推向模型言说该 object 时的自身概念"）。
5. **干预**：对证据位置做保范数旋转 $h'_i=\mathrm{normalize}(h_i+s\,\sigma\|h_i\|\,u_i)$，$s{=}\pm1$（toward / away），$\sigma{=}1$；干预层为解码器中深处（$L=n/2$，LLaVA 16/32）。同时以同位置、同强度的**随机单位方向**为对照。
6. **响应观测**（每次干预前向同时记录）：
   - `mention_dlogit`：每个 object 首次提及 token 的 logit 增量（输出侧信念响应）；
   - `lens_dread`：每个 object 锚 token 在更深层（含末端 $n{-}1$ 层入口）lens 读出的增量（**内部传播响应**）；
   - 三段 ΔNLL / flip（叙述完整性监测）。

### 2.2 冻结分数

$$
\mathrm{SAI}(q)=\frac{z(P^{31}_{\text{unembed}})+z(P^{31}_{\text{mention\_state}})}{2}+z(\text{neg\_support})
$$

其中（每 object 取首次提及，样本内对 object 取均值，$z$ 为模型内总体标准化）：

- **传播响应** $P^{31}_{m}(o)=\big(\Delta\text{reading}^{31}_{+}-\Delta\text{reading}^{31}_{-}\big)/2$：锚模式 $m$ 下，toward 与 away 干预造成的末端层锚 token 读出之差的一半；
- **支持亏缺** $\text{neg\_support}(o)=-\text{logit}_{\text{baseline}}(\text{首提 token})$。

分数越高 = 幻觉风险 / 不确定性越高，与 PPL、SE、UMPIRE 方向一致。

### 2.3 测量对象说明（改进要求 §4.1）

SAI 测量的是**声称的视觉语义证据与其信念之间的因果耦合结构**：传播响应是"注入的 object 语义能否被模型整合进视觉读出"的因果量，支持亏缺是"声称在模型自身前缀下的被支撑程度"。二者都不是一般视觉依赖度——干预不改变信息可用性（保范数旋转），且随机方向对照证明信号是锚语义特异的（§6.2）。

### 2.4 与既有工作的区别

| 方法 | 机制 | 与 SAI 的区别 |
|---|---|---|
| PPL / SE / UMPIRE | 输出空间统计 | SAI 测内部因果响应 |
| VSE (2606.31407) | 图像空间扰动 + 采样多样性；用 LogitLens 度量视觉熵 | SAI 在隐空间、object 级、方向明确的 toward/away 对比 |
| VL-Uncertainty / VAUQ | 输入编辑/遮挡的输出一致性 | SAI 不破坏输入信息，且观测传播而非输出一致性 |
| MALP / Embedding-Perturbation | 固定随机扰动的 NLL 响应 | SAI 的方向是 object 语义锚，响应是语义读出传播，有随机方向对照 |
| VGS（本仓库） | 答案→视觉注意力占比（相关） | SAI 是因果干预 + 语义特异；二者信号来源不同 |
| LSB（本仓库） | 随机方向的叙述刚性 | SAI 的方向有明确语义含义且 object 级定位；响应观测在读出空间而非 flip 率 |
| CRS（本仓库） | 静态词数 + 表征刚性 | SAI 含干预响应分量与 object 级证据定位 |

## 3. 开发与冻结协议

开发模型 **LLaVA-1.5-7B**（其 400 条 LUH 子集）；全部设计选择在开发数据上确定后冻结，Qwen / InternVL 只换算层深（$L{=}n/2$、末端读出层 $n{-}1$）。

开发过程中的主要决定与负结果（均为后续设计的依据）：

1. **首提位置是唯一可用的输出侧观测点**：后续提及被前文锁定（copy 效应），干预响应比首提小 4–5 倍且无分离。
2. **静态 lens 读出不能作分数**：修正锚 token 后静态读出在 ViLP 与 HallusionBench 上方向相反（0.63 vs 0.44），池化互相抵消——LUH 子集内数据集构成差异会制造虚假池化增益（LSB v1 的同类教训）。
3. **输出侧耦合 C 弱于内部传播响应**：首提 logit 的 toward-away 对称分量 C 池化 AUROC 0.57–0.63，且部分与基线 logit 饱和混淆；改为观测**末端层读出传播** P31 后达 0.65，并修复了静态读出在 MM-Vet 上的失效（0.467→0.605）：toward/away 是样本内对比，天然免疫 lens 的跨样本尺度漂移。
4. **σ=2 以上深层干预在 fp16 下溢出**（LLaVA 数值脆弱）→ 全族改用 bf16（SAI 只用 within-run Δ，与生成期 fp16 概率无一致性要求）。
5. **锚 token 前导空格 bug**：一度所有 object 解析到 token 29871（"▁"），早期"object 级"结果实际是全局空格方向干预；发现后全部作废重跑。此教训已写入单元测试。
6. **分数选择**：在 30 个候选（C×24 变体、P31×4、support、组合）上按"池化 AUROC + 逐数据集最小值"选择 `P31mean+negS`（0.675 / min-ds 0.605）；加入静态读出或输出侧 C 均不改善 min-ds。

## 6. 分析

### 6.1 机制：为什么"高传播 + 低支持"标记 LUH

LUH 幻觉是"自信地编造"。真实读图产生的 object 声称被证据双向钉住：基线首提 logit 高（前缀与证据一致），且末端读出已饱和——再向锚方向注入语义，读出抬升有限（响应-饱和）。编造的 object 缺乏真实证据：首提 logit 低（支持亏缺），读出远未饱和——注入语义可以被网络线性放大并向前传播（高可塑性）。两个分量分别捕捉"没被撑住"与"可以被任意注入"，其组合在三个数据集上一致。

### 6.2 因果特异性：随机方向对照

同位置、同强度（σ=1、L=16、top-16）的随机单位方向干预下，传播响应 P31rand 的 LUH AUROC 为 **0.513（≈随机）**，与语义锚 P31 的相关 **0.024**——传播信号不是一般扰动损伤，而是锚语义特异的因果响应。这正是"intervention response 而非 perturbation damage"的证据。

### 6.3 与静态读出的关系（诚实披露）

P31 与静态读出（末端 lens 读出的负值）总体相关 −0.83：静态读出本身池化 0.653，但逐数据集不稳定（MM-Vet 0.467）；P31 是其**样本内对照化**的因果版本，修复了跨数据集稳定性（min-ds 0.605）。将 P31 对静态读出残差化后剩余信号 0.571（HallusionBench 0.646）——即传播响应约 2/3 的判别力与"证据读出强弱"共享来源，1/3 来自 toward/away 对照独有的动态信息。冻结分数选择 P31（而非静态读出）的理由是跨数据集稳定性与因果可解释性，而非池化数字。

### 6.4 混淆披露

- **覆盖**：约 5% 样本（多为极短 HB 是/否回答）抽不出 object，SAI 无定义，评估在交集上进行并报告覆盖；这些样本不产生虚假优势。
- **object 提取质量**：Qwen3-4B 偶漏（landmark/chart 元素在 v1 提示词下漏抽，v2 已修复）；残余噪声进入锚方向但不使用标签。
- **多子词 object**：锚取首子词（如 "wrench"→"w"），对极通用首子词的 object 语义指向偏弱。
- **z 标准化使用模型内无标签总体**（与 UMPIRE 自适应 alpha 同类的无标签全局量）。

## 7. 局限

1. 每样本 4–6 次前向（冻结条件），成本介于 VGS（1 次）与 LSB（64 次）之间。
2. 依赖 logit lens 的可读性：对 lens 读出弱的中层结构（某些模型/层）定位质量下降。
3. 无 object 样本（~5%）不可评分。
4. 首子词锚与多子词 object 的语义不完全对齐。
