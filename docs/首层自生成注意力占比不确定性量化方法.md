# 首层自生成注意力占比（EPAR）不确定性量化方法

EPAR（Early Prelim Attention Ratio）是 VGS（视觉基础分数）的改进方法，两者共享同一条 teacher-forcing 注意力分析流水线。本文档记录改进动机、迭代过程、最终定义与实验结果。

## 1. 动机与改进路径

### 1.1 VGS 的问题

VGS v1 测量答案预测位置对视觉 token 的注意力占比（后 2/3 解码层、全头求和），在 LUH 子集上 AUROC 为 0.569–0.602。对注意力区域做分解后发现其结构性缺陷：

> **分母被 prompt 文本主导。** 答案行的注意力分母 = 视觉 + prompt 文本 + 已生成文本（prelim）三个区域之和，实测 prompt 文本质量是视觉质量的 20–30 倍。VGS v1 的比值因此主要测量 prompt 文本注意力的波动，而非"视觉 vs 语言先验"的竞争。

### 1.2 三个候选改进（dev = LLaVA-1.5-7B，400 条 LUH 子集）

在保留同一次前向传播的前提下，将注意力分解为三个互斥区域，得到候选分数：

| 候选 | 定义 | 依据 | dev AUROC |
|---|---|---|---|
| v1 | $-A_{vis}/(A_{vis}+A_{txt}+A_{pre})$（原 VGS） | — | 0.592 |
| v2 | $-A_{vis}/(A_{vis}+A_{pre})$（去掉 prompt 文本） | PAS：幻觉时模型"无视图像、依赖已生成文本"，竞争发生在视觉与自生成文本之间 | 0.606 |
| v3 | 视觉注意力分布归一化熵（弥散度） | ADS：幻觉 token 的视觉注意力弥散 | 0.473（方向相反，弃用） |

v2 的逐层分析进一步显示：**信号集中在首层（layer 0），v2@layer0 = 0.726**，且从首层起逐层加入会单调稀释信号——与 PAS 的层消融结论一致（"早期层收集信息，后期层处理信息"）。

### 1.3 第一轮冻结与迁移失败

冻结 v2@layer0 后在 Qwen2.5-VL 上验证失败（0.540，低于 VGS v1 的 0.602）。诊断发现失败根因不是层选择本身，而是**动态分辨率混淆**：

- Qwen2.5-VL 的视觉 token 数跨度 63–16284，与 v2@layer0 分数相关系数 -0.67；
- 首层注意力接近内容无关的均匀模式，视觉区域质量随视觉 token 数机械增长，跨模态竞争比退化为"图像有多大"的代理；
- 剔除 n_vis 效应后 qwen 首层信号归零（0.520）。

### 1.4 最终方法：EPAR

对比早期层与晚期层的两个稳健候选后，冻结 **EPAR**：首 4 层平均的 prelim 注意力占比。选择依据：

1. **dev 上最强**（0.728，与单首层 0.730 持平，4 层均值方差更小）；
2. **对两个已知混淆不变**：分子是 text→text 注意力，不含视觉区域质量，不受动态分辨率影响（qwen 上与 n_vis 相关 -0.06）；分母归一化总注意力，不受答案长度影响（llava 上剔除长度效应后 0.728→0.720）；
3. 9/9 模型×数据集单元 AUROC 均 ≥ 0.55，无跌破随机的单元（对照组 v2@末4层 在 internvl/mmvet 上为 0.468）。

## 2. 方法定义

给定完整序列（prompt + teacher-forcing 贪心响应），设答案预测位置集合 $\mathcal{A}$（与 VGS 相同的答案跨度），对**前 4 个解码层**（$\ell \in \{0,1,2,3\}$）的全部注意力头求和：

- $A_{pre} = \sum_{\ell,h,i \in \mathcal{A},\, j \in \mathcal{P}(i)} A^{(\ell,h)}(i,j)$：答案行 $i$ 对其**已生成 token**（$[L_{prompt}, i]$，含推理脚手架与答案前缀）的注意力质量；
- $A_{vis}$、$A_{txt}$：对视觉 token、prompt 文本的注意力质量。

$$
s_{\text{EPAR}} = \frac{A_{pre}}{A_{vis} + A_{pre} + A_{txt}}
$$

分数越高（答案生成越多地路由到模型自己已生成的文本）→ 幻觉风险越高。

### 2.1 测量对象说明

EPAR 测量**答案生成对自身已生成文本的信息依赖强度**。其幻觉风险解释来自 PAS 的互信息论证：若 $I(\mathbf{v}; Y_k \mid \mathbf{y}_{<k}, \mathbf{t})$ 低——即给定自生成文本后答案几乎不依赖图像——模型处于"替代运行模式"，从自身输出复制而非从视觉证据读取。低不确定性幻觉（PPL/SE/UMPIRE 均失灵）正是这种模式的典型产物：输出空间看起来自信且稳定，但信息路由已经暴露答案来源是自回归自我强化。它测量的不是一般视觉依赖程度（分子不含视觉项），而是幻觉风险的信息来源。

### 2.2 为什么是前 4 层

早期层注意力反映原始信息路由（复制/聚集），深层注意力被任务处理与语言先验改写。前 4 层取平均而非单层，为降低单层方差；层宽在 dev 上确定后冻结，对三个模型统一取前 4 层（llava 32 层、qwen 28 层、internvl 36 层，均取绝对前 4 层）。

### 2.3 计算复杂度

与 VGS v1 完全相同：单次 teacher-forcing 前向传播（chunked eager attention），无额外采样或扰动。累加器额外记录每层三区域质量与逐层弥散熵，仅增加常数级显存。

## 3. 实验结果

### 3.1 LUH 子集（每模型 400 条：200 低不确定性幻觉 + 200 匹配非幻觉）

| 模型 | 方法 | AUROC [95% CI] | AUPRC | PRR | ECE |
|---|---|---|---:|---:|---:|
| LLaVA-1.5-7B | VGS v1 | 0.592 [0.533, 0.647] | 0.598 | +0.202 | 0.176 |
| LLaVA-1.5-7B | **EPAR** | **0.728 [0.678, 0.776]** | **0.728** | **+0.478** | **0.104** |
| Qwen2.5-VL-7B | VGS v1 | 0.602 [0.543, 0.657] | 0.601 | +0.202 | 0.299 |
| Qwen2.5-VL-7B | **EPAR** | **0.608 [0.550, 0.664]** | 0.591 | **+0.246** | **0.144** |
| InternVL3.5-8B | VGS v1 | 0.569 [0.508, 0.627] | 0.563 | +0.189 | 0.115 |
| InternVL3.5-8B | **EPAR** | **0.596 [0.543, 0.656]** | **0.584** | **+0.195** | **0.087** |

（三 baseline 在同子集上 AUROC 均约 0.5，见 VGS 文档。）EPAR 相对 VGS v1 在三个模型上 AUROC 分别 +13.6 / +0.7 / +2.7 个点，AUROC 置信区间下界 0.543–0.678 均高于 0.5；PRR、ECE 一致改善，AUPRC 在 llava/internvl 改善、qwen 持平（0.591 vs 0.601）。

### 3.2 分数据集（LUH 子集内）

| 模型 | ViLP | HallusionBench | MMVet |
|---|---:|---:|---:|
| llava | 0.687 | 0.720 | 0.649 |
| qwen | 0.566 | 0.603 | 0.604 |
| internvl | 0.558 | 0.620 | 0.734 |

9/9 单元 ≥ 0.55。

### 3.3 完整测试集（不退化检查）

全集 = 三个数据集全部有有效 judge + UQ + 前向的样本（每模型约 1550 条；无图与无效响应样本按 VGS 相同口径跳过）。

| 模型 | PPL | SE | UMPIRE | **EPAR** |
|---|---:|---:|---:|---:|
| LLaVA-1.5-7B | 0.530 | 0.590 | 0.617 | **0.683** [0.652, 0.713] |
| Qwen2.5-VL-7B | 0.507 | 0.608 | 0.564 | **0.619** [0.586, 0.656] |
| InternVL3.5-8B | 0.571 | **0.655** | 0.607 | 0.571 [0.536, 0.604] |

- llava / qwen：EPAR 为全集最优方法（llava 领先最强 baseline +6.6 点）；
- internvl：EPAR（0.571）低于 SE（0.655）与 UMPIRE（0.607），与 PPL 持平。EPAR 针对的 LUH 场景上它仍是最优（0.596），但全集上 internvl 的幻觉信号更多被输出空间方法（SE）捕获。实际使用中 EPAR 与 SE 互补：internvl 全集应以 SE 为主。

结论：EPAR 在全集上无崩溃（三模型 0.571–0.683），重点目标（LUH 子集）三模型全面改善，满足"重点报告 LUH 增益、全集不退化"的要求；internvl 全集相对 SE 的劣势是已知边界。

## 4. 迭代过程记录

| 轮次 | 冻结内容 | dev (llava) | 验证结果 | 结论 |
|---|---|---|---|---|
| 1 | v2@layer0（首层视觉-自文本竞争比） | 0.726 | qwen 0.540（失败），internvl 0.603 | 动态分辨率混淆（n_vis 与分数相关 -0.67），弃用 |
| 2 | EPAR（首 4 层 prelim 占比） | 0.728 | qwen 0.608、internvl 0.596 | 三模型均不劣于 VGS v1，llava 大幅领先 |

第一轮的 n_vis 诊断使用了验证模型数据，特此记录以保证过程透明；第二轮的候选集合（v5 早期 vs v2 晚期）在 dev 上排序为 v5@[0..3] (0.728) > v2@[L-4..L] (0.620)，dev 结论与最终选择一致。

## 6. 参考文献

- PAS: Prelim Attention Score for Detecting Object Hallucinations in Large Vision–Language Models (arXiv:2511.11502)。EPAR 是其 prelim 注意力信号在答案级 UQ 场景的适配：对象级 CHAIR 标签 → 答案级 judge 标签；单层 → 前 4 层均值；并给出动态分辨率混淆的失败分析。
- Beyond the Global Scores: Fine-Grained Token Grounding as a Robust Detector of LVLM Hallucinations (arXiv:2604.04863)。其"弥散注意力"假设（ADS）在本设置上方向相反（LUH 子集 v3 = 0.473），已弃用。
