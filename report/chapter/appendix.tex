\section{Supplementary Notes and Ablation Studies}
\label{sec:appendix_a}

\subsection{Dataset Details}
\label{subsec:appendix_datasets}

\textbf{ViLP} \citep{luo2025probing}. The Hugging Face release contains 300 distinct questions, each paired with three images and answers: one prior-consistent answer and two test answers that require joint use of textual and visual evidence. Expanding all three pairings yields 900 QIA instances. Each QIA is evaluated independently, while grouped statistics and bootstrap resampling cluster by the original question identifier to avoid treating the three related instances as independent. The benchmark creates direct conflicts between language priors and visual evidence, as illustrated by Case~1 in \Cref{subsec:representative_cases}.

\textbf{HallusionBench} \citep{guan2024hallusionbench}. HallusionBench contains 1,129 instances: 951 in the \texttt{image} split and 178 in the \texttt{non\_image} split. It covers Visual Dependent and Visual Supplement settings and includes figures, charts, maps, tables, OCR, illusions, mathematics, and video frames. Both splits are used in the full evaluation; instances with \texttt{visual\_input=0} receive no image and are excluded only when constructing the ERA difficult subsets, which require visual tokens.

\textbf{MM-Vet} \citep{yu2024mmvet}. The \texttt{test} split contains 218 open-ended visual questions covering recognition, OCR, knowledge, spatial awareness, language generation, mathematics, and combinations such as OCR+math. Reference answers may be words, numbers, lists, short sentences, or descriptions. Correctness is judged semantically from the content inside \texttt{<answer>}.

\subsubsection{Response Instruction (\texttt{xml-lora-zero-shot-v1})}

The image, question, and response instruction are placed in one user message:

\begin{lstlisting}
[Image]
{official_image}

[Question]
{official_question}

[Response requirements]
Answer using exactly these three XML tags once and in order, with no line breaks
and no text outside them: <vision>relevant visible evidence</vision><reasoning>brief
reasoning</reasoning><answer>concise final answer</answer>
\end{lstlisting}

\subsubsection{Judge System Prompt (\texttt{closed-source-correctness-hallucination-v1})}

\begin{lstlisting}
You are an impartial judge for a multimodal response organized into visual
observations, reasoning, and a final answer.

Task 1: Hallucination
Judge hallucination only from the visual observations and reasoning parts.
Multimodal hallucination means content inconsistent with the image, question,
context, or facts; it is not the same as every error. Calculation mistakes,
flawed reasoning, or wrong formulas are usually general/reasoning errors.
Fabricating nonexistent objects, attributes, relations, numbers, conditions,
evidence, or introducing unsupported premises/rules/facts is hallucination.

Use the full 0-6 scale:
- Rating 6: very informative with good analysis or reasoning, no hallucination.
- Rating 5: very informative, no hallucination.
- Rating 4: somewhat informative, no hallucination.
- Rating 3: not informative, no hallucination.
- Rating 2: very informative, with hallucination.
- Rating 1: somewhat informative, with hallucination.
- Rating 0: not informative, with hallucination.

The hallucination label MUST follow this threshold:
- rating 0, 1, or 2 => hallucination=true.
- rating 3, 4, 5, or 6 => hallucination=false.

If hallucination=true, hallucination_types must be "vision_hallucination" for
false visual observations, "reasoning_hallucination" for unsupported reasoning
claims, or both.

Task 2: Correctness
Judge correctness only from the final answer part. Compare it with the ground
truth provided in the user prompt.
\end{lstlisting}

\subsection{Format-Oriented LoRA Fine-Tuning}
\label{subsec:appendix_lora}

The format data are constructed from the official VQAv2 train2014 questions, human answers, and corresponding COCO images. Candidate questions require strong annotator agreement and are balanced across question types, with at most one question retained per image. The final 5,000 distinct image--question pairs are split with seed~42 into 4,000 training and 1,000 validation examples, with no image or question overlap. Qwen3.7-Plus generates task-relevant visual evidence and concise reasoning from the real image, question, and majority answer. Valid examples are wrapped as a single-line \texttt{<vision>/<reasoning>/<answer>} target.

Each model has a separate LoRA adapter but shares the same data split, target format, and core optimization settings. LoRA is applied only to \texttt{q\_proj} and \texttt{v\_proj} in the language-model attention layers; the vision encoder, multimodal projector, and all remaining base parameters are frozen. Loss is computed only on the response. LLaVA and Qwen use a maximum sequence length of 1,024, while InternVL uses 4,096 to accommodate its native input representation.

\subsection{XML Format-Adaptation Ablation}
\label{subsec:appendix_xml_ablation}

This ablation begins with 500 question instances sampled without replacement from the common pool for which all three XML-LoRA models produce complete XML. The set contains 204 ViLP, 243 HallusionBench, and 53 MM-Vet instances. The XML-LoRA condition reuses the greedy responses and Gemini-3.7-Flash labels from the main experiment. The native condition loads no adapter and uses a prompt requesting Visual Observation, Reasoning, and Final Answer; its complete raw response is judged by the same Gemini model and prompt.

Only instances for which the native response actually contains all three requested sections enter the content comparison. This leaves 217 paired samples for LLaVA, 473 for Qwen, and 500 for InternVL. Differences are defined as XML-LoRA minus native. Confidence intervals use 1,000 group-bootstrap replicates and $p$ values use exact McNemar tests.
