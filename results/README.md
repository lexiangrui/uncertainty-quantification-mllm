# Curated results

本目录在 Git 中仅保留轻量、正式且有助于复核结论或复现实验的 JSON：

- 三个模型在三个数据集上的最终指标；
- 由 Git LFS 管理的完整正式生成 JSONL；
- 人类对齐后的正式 Judge 标签；
- `analysis/` 下的全部正式分析结果；
- XML 格式消融的 manifest 与正式分析表；
- 代表案例、LUH 子集索引及人类对齐 finalization manifest。

原始 Judge 输出、hidden/token sidecar、人工标注工作区、图片和 LoRA adapter 仅保存在集群，不纳入 Git。
